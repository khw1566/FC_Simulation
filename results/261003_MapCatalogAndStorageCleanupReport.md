# 지도 분류 및 프로젝트 용량 정리

- 일본: 칸몬해협, 큐슈.
- 한국: 울산과학대학교 서부캠퍼스 5km, 울산광역시 80km, 경상도 140km.
- 테스팅: 평지 맵.
- 5km 지형은 사용자의 답변에 따라 기존 서부캠퍼스 지형을 유지했다.
- 경상도 140km는 기존 포항·울산·부산 동남권 지형의 표시 이름이다. 경상도 전체를 포함하는 새 지형을 수집한 것은 아니다.
- 큐슈는 기존 칸몬해협 자산을 공유하는 준비용 맵을 유지했다. 큐슈 독립 실측 지형 수집은 이번 범위에 포함되지 않는다.

## 화면과 참조 정리

- 맵 모델에 분류 필드를 추가하고 선택 화면에 일본·한국·테스팅 제목 아래 맵 버튼을 배치했다. 한국어·영어 전환과 선택 강조를 유지했다.
- 레지스트리와 실행용 맵 디렉터리에는 6개 맵만 남겼다. 울산 60km와 시모노세키항 3km를 제외했다.
- 울산공항 모델과 배치 정보를 `assets/generated/airport` 공용 자산으로 이전했다. 80km 맵, 미리보기, 자산 조사 화면, 공항 생성기·인덱서 참조를 수정했다.
- 공항·유적·도로 검사와 맵 생성 후 기본 전처리 대상에서 삭제된 맵 참조를 수정했다.
- 자산 매니페스트에 변경된 메타데이터 해시와 공용 공항 자산을 기록했다. 압축 원본은 ZIP 경로·ZIP 해시·내부 항목·원본 해시로 추적한다. 양쪽 모듈 인덱스를 갱신했다.

## 용량

- 전체 프로젝트: 2,176,576,794바이트 → 1,464,130,705바이트, 약 712MB 감소(32.7%). 보고서 등 후속 소형 파일에 따라 실제 측정은 조금 달라질 수 있다.
- Godot 프로젝트: 약 1.53GB → 0.91GB.
- 전체 파일: 18,733개 → 13,344개.
- 울산 60km 원본, 시모노세키항 원본, 울산 80km 수집 캐시와 병합 원본을 `data/archives`에 ZIP 보관했다. 압축 전후 모든 파일의 개수·길이·SHA-256을 비교한 뒤 원래 폴더를 제거했다.
- 현재 80km·140km 실행에 필요한 병합 JSON과 분할 스트리밍 파일은 보존했다. 원본 JSON은 분할 캐시 검증에도 사용되므로 임의로 삭제하지 않았다.
- 재수집·재병합·기존 60km 코어를 이용한 지형 재생성 전에는 [원본 복원 안내](../data/archives/README.md)에 따라 필요한 보관본을 복원해야 한다. 일반 게임 실행에는 복원이 필요 없다.

## 검증

- 실제 Godot 4.3 Vulkan 실행: 6개 맵 분류, 메타데이터 자산 존재, 미리보기 경로, 한국어·영어 목록, 모든 맵 버튼 선택, 제외된 맵 선택 거부, 공용 공항 씬 파싱 모두 통과.
- 화면 이미지: `261003_map_categories.png`, 검사 결과: `261003_map_catalog_validation.json`.
- 공항 이전 후 울산 80km 진입·중복 요청 차단·취소 복구·메뉴 복귀·FPS HUD 검사 통과.
- 해당 시작 위치의 정지 상태 3초 평균: 60.17 FPS, 최대 프레임 간격 24.34ms. 로딩 23.327초. 다른 맵 전체 비행 검증은 수행하지 않았다.
- 기존 이미지 직접 로드 및 종료 시 ObjectDB 경고는 남아 있다. 이번 실제 실행 로그에 파싱 오류나 런타임 ERROR는 없었다.
