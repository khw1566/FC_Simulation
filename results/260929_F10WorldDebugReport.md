# F10 월드 디버그 표시

- F10으로 디버그 HUD를 켜거나 끕니다. 기본은 꺼짐입니다.
- 플레이어 XYZ, 위경도, FPS를 표시합니다.
- 카메라 중앙 광선의 물리 충돌 노드 경로를 표시합니다.
- 충돌체 없는 바다 등의 확인을 위해 렌더링 서버의 광선 후보 중 가까운 8개 메시를 삼각형 검사하고 가까운 교점 3개를 표시합니다.
- 각 후보의 노드 경로, 재질·셰이더 경로, 거리, 교점 XYZ, 수계 마스크 값, 지형 높이를 표시합니다.
- 켜진 동안 0.5초 간격으로 조사하며 메시 면을 캐시합니다. 복잡한 메시가 많은 위치에서는 검사 비용이 발생할 수 있습니다.
- 메시 교차는 셰이더의 변위·절삭·투명도와 MultiMesh 내부 개별 인스턴스를 반영하지 않습니다. 따라서 최종 화면 픽셀의 확정 대상이 아닌 메시 후보로 명시했습니다.
- 첨부 화면의 회색 면이 어떤 노드인지는 이미지 자체만으로 확정하지 않았습니다. 이번 변경은 해당 대상의 경로와 수계 정보를 현장에서 확인하기 위한 디버그 기능입니다.
- 게임을 다시 실행한 후 문제 화면에서 F10을 켜면 됩니다. 이번 작업에서 실행 테스트는 수행하지 않았습니다.
