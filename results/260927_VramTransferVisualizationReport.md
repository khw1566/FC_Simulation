# 260927_VramTransferVisualizationReport.md - 맵 로딩 시 VRAM 데이터 전송 시각화 및 로딩 화면 UX 개선 보고서
본 문서는 가상 지형 공간 진입 시 호스트 시스템 메모리에서 GPU VRAM으로 데이터가 전송되는 하드웨어 파이프라인의 실시간 시각화 구현 및 로딩 화면 UX 고도화 작업 내역을 기록합니다.

## 1. 개요 및 요구사항
- **VRAM 데이터 파이프라인 시각화:** DEM 표고 텍스처, 광학 수계/스플랫맵 텍스처, 3D 지형 청크 VBO, 시가지 3D 벡터 구조물(도로/교량/터널/건물) VBO가 PCIe DMA 버스를 통해 GPU VRAM에 적재되는 전 과정을 시각화.
- **로딩 화면 UX 대폭 개선:** 단순 프로그레스 바 형태에서 탈피하여 맵 제원 상세 표출, 비행 조작 단축키 뱃지 그리드, 3.5초 주기 순환형 비행 역학 팁, 16개 VRAM 메모리 뱅크 매트릭스 점등 효과 제공.

## 2. 세부 구현 내역

### 2.1 16-Bank VRAM 메모리 할당 매트릭스 및 실시간 계측 (`LoadingScreenView`)
- **16개 메모리 뱅크 격자 (`BankGrid`):** B00부터 B15까지 16개의 독립된 VRAM 메모리 뱅크 블록을 구성하고, 전송 단계에 따라 순차적으로 미할당(어두운 회색)에서 활성화(고대비 하이라이트)로 상태 전이.
- **실시간 VRAM 텔레메트리 연산:**
  - 기본 시스템/엔진 점유: 38.0 MB
  - 16-bit DEM 표고 텍스처(Float RF): +16.0 MB
  - 광학 수계 마스크 및 4채널 스플랫맵(R8+RGBA8): +20.0 MB
  - 절차적 3D 지형 청크 VBO(64 청크 타일): +46.0 MB
  - 시가지 3D 벡터 구조물 VBO(도로망/교량/터널/건축물): +36.0 MB
  - 총 VRAM 사용량, 텍스처 VRAM, 지오메트리 버퍼 VRAM 분리 계측 및 `Performance.get_monitor(Performance.RENDER_VIDEO_MEM_USED)` 실측치 융합.
- **PCIe 4.0 DMA 버스 전송 스트림 애니메이션:**
  - `[HOST RAM (DDR5)] ===> PCIe 4.0 x16 DMA BUS ===> [GPU VRAM (GDDR6)]`
  - 전송 중일 때 데이터 패킷 펄스 애니메이션 및 14.1 ~ 14.8 GB/s 실시간 전송 대역폭 표출.

### 2.2 4대 핵심 자산 VRAM 적재 상태 카드
각 자산의 규격 및 적재 단계를 직관적으로 확인할 수 있는 상태 카드 구현:
- `[1] 16-bit DEM 표고 높이맵 텍스처 (Format: Float RF)`: 대기 -> 전송중 -> VRAM 적재완료 [16.0 MB / RF]
- `[2] 광학 수계 마스크 및 4채널 피복 스플랫맵 (R8 + RGBA8)`: 대기 -> 전송중 -> VRAM 적재완료 [20.0 MB / R8+RGBA8]
- `[3] 지형 청크 버텍스/인덱스 버퍼 (Terrain Mesh VBO)`: 대기 -> 버퍼 업로드중 -> VBO 바인딩완료 [46.0 MB / 64청크]
- `[4] 시가지 3D 벡터 구조물 (도로/교량/터널/건물 VBO)`: 대기 -> 버퍼 업로드중 -> VBO 바인딩완료 [36.0 MB / 기하버퍼]

### 2.3 로딩 화면 전술 HUD 및 UX 개선 (`loading_screen.tscn`)
- **맵 정밀 제원표 (Specs Panel):** 선택된 맵 모델과 연동하여 월드 공간 규모(예: 60,000m x 60,000m), 표고 해발 범위(-50.0m ~ 750.0m), 청크 격자 분할(8x8, 64 청크), 비행 개시 스폰 좌표를 명시.
- **비행 조작 가이드 뱃지:** `[W/A/S/D] 비행`, `[SPACE/SHIFT] 고도`, `[1~4] 기어(마하10)`, `[C] 충돌`, `[TAB] 지도`, `[M] 등고선` 키 캡 UI 배치.
- **순환형 비행 팁 캐러셀:** 3.5초 주기로 고고도 가시거리(75km), 소형 건물 자동 생략 최적화, 기어 변속 역학, 충돌/중력 토글 등 전문 비행 팁 자동 전환.

### 2.4 단계별 로딩 시퀀스 조율 (`LoadingManagerService`)
씬 전환과 백그라운드 리소스 빌드가 일어나는 동안 VRAM 전송 시각화가 유기적으로 동기화되도록 6단계 시퀀스로 재설계:
- 1단계 (15%): 호스트 시스템 메모리 및 DMA 버스 초기화
- 2단계 (38%): 16-bit DEM 높이맵 텍스처 VRAM 전송 및 씬 전환
- 3단계 (62%): 수계 마스크 및 피복 스플랫맵 VRAM 바인딩
- 4단계 (82%): 절차적 3D 지형 청크 버텍스 버퍼 VBO VRAM 적재
- 5단계 (95%): 시가지 3D 벡터 구조물 VBO VRAM 적재
- 6단계 (100%): GPU 렌더링 파이프라인 동기화 완료 및 진입
