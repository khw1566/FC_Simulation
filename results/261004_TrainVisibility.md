# 울산 열차 표시 수정

- 시작 시 시뮬레이션 시간을 한 차례의 전체 운행 시간만큼 진행하여 동해선과 KTX가 양방향 노선 전역에 분포한다. 기존 배차 간격과 역 정차 시간은 유지한다.
- 모든 철로 메시의 생성이 끝나기를 기다리지 않고 경로 좌표 준비 직후 열차 서비스를 시작한다.
- 표시 거리를 하드코딩된 6,500m에서 services.json의 render_distance_m(12,000m)으로 연결한다.
- 최대 표시 편성 수는 출발 순서가 아닌 관찰자와의 거리를 기준으로 적용한다.
- 운행 서비스 생성 완료를 로그에 기록한다.
- Godot 4.3 --check-only로 수정 모듈과 의존성 문법 검사 통과. 전체 맵 실행 및 실제 화면에서의 이동은 검증하지 않았다.
- 현재 기능 적용 대상은 울산광역시 80km 맵이다. 이미 실행 중인 게임에는 변경이 자동 적용되지 않으므로 다시 실행해야 한다.
