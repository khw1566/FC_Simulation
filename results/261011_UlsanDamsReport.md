# 울산 용수댐 조사 및 배치 결과
사연댐·대곡댐·대암댐·선암댐·회야댐 5종을 조사하고 경량 모델과 지도 배치 코드를 추가했다. 농업용 저수지 전체와 사방댐은 이번 범위에 포함하지 않았다.

## 조사 및 채택 제원
K-water 지역본부 시설현황과 울산시 도시경관기록의 제원을 사용했다. 댐마루 폭·사면비·난간은 시각화용 추정이며 측량 모델이 아니다.

- [K-water 선암댐 시설소개](https://www.kwater.or.kr/busi/sub02/facilitiespresent03Page.do?s_mid=1515): 선암댐 형식·높이·길이. 같은 페이지의 사연댐 본문에는 다른 댐 제원과 혼재한 값이 있어 지역본부 표를 채택했다.
- [울산시 호수·저수지 기록](https://www.ulsan.go.kr/archive/us/nUlsan/NL/LR.do): 회야댐 높이 24.5m, 길이 424m.
- [울산시 회야댐 수문 설치 발표](https://www.ulsan.go.kr/u/rep/bbs/view.do?bbsId=BBS_0000000000000027&dataId=183282&mId=001004003001000000): 향후 사업으로 구분하여 수문을 생성하지 않았다.
- 좌표·출처·불확실성은 `config/ulsan_dams.json`과 `godot_project/assets/generated/ulsan_dams/catalog.json`에 기록했다. 항공영상 촬영일은 미확인이다.
- 대암댐 초기 서남단 도로 후보는 항공영상으로 유입부임을 확인하여 배치에서 제외했다. 최종 배치는 북동단 본댐이다.
- 공식 길이와 공개 마루 축선 길이의 차이는 숨기지 않았다. 로컬 모델은 공식 길이로 생성하고 지도 배치는 공개 축선 양 끝에 맞춘다. 특히 선암댐은 직선 산책로가 공식 제원보다 약 83m 짧아 X 배율 약 0.749를 적용했다. 실제 댐 전체 경계의 측량 확인은 남아 있다.

## 생성 및 연결
전용 경로 `godot_project/assets/generated/ulsan_dams`에 GLB 10개와 자체 완결 LOD TSCN 5개, 카탈로그·README·매니페스트를 추가했다. 기존 에셋 삭제나 교체는 없다.

- 모델 종류는 5종이다. GLB 근경·원경과 TSCN은 같은 댐의 표현 파일이다.
- 근경 삼각형: 사연 1,900 / 대곡 1,340 / 대암 1,508 / 선암 1,436 / 회야 1,832.
- 원경 삼각형: 사연 1,444 / 대곡 992 / 대암 1,028 / 선암 956 / 회야 1,208.
- 무광 단색, 외부 텍스처 없음. 근경 3.5km, 원경 24km 거리 소거. 근경 메시 기반 충돌 포함.
- `BuildingRoadManager`의 지형 준비 후 단계에 `DamLandmarkManager`를 연결했다. 지도 종류와 bbox 양 끝 포함 여부를 확인하므로 범위 밖의 댐은 생성하지 않는다. 전체 게임 씬·지도 설정은 수정하지 않았다.
- 지도 중앙 원점, 경도→X·북위 감소→Z 좌표식을 기존 코드와 통일했다. 축별 지도 배율과 축선 방향을 보존했다.
- 댐마루 기준 높이는 현재 DEM의 축선 내부 17개 표본 90백분위 +0.35m이다. 기준 품질 래스터 참고값은 사연 64.176m, 대곡 124.691m, 대암 54.002m, 선암 30.778m, 회야 32.403m이다. 측량 표고나 실제 저수위가 아니다.
- 기존 DEM에 이미 포함된 제방과 겹치므로 상부·사면만 지표 +0.45m 이상으로 맞추고 충돌을 다시 만든다. 양 끝 사면 폭은 시각화용으로 줄였다. 공식 단면을 재현한 토목 설계 모델이 아니다.
- 원본 수계·DEM, 기존 높이 보정, 기존 공유 메시를 변경하지 않는다. 공유 생성 매니페스트의 비대상 8,220개 항목을 보존했다.
- 실행 시 에셋 생성이나 색인 갱신을 하지 않는다. 에셋 프리뷰 EXE는 재빌드하지 않았다.

## 확인한 범위
전체 맵을 실행하지 않고 `previews/ulsan_dams/project`의 별도 Godot 4.3 Compatibility 프로젝트에서 확인했다. 최초 headless 정리 단계의 dummy 렌더러 메시 경고는 실제 Compatibility 렌더러로 재검사해 발생하지 않았다. 최종 로그는 `fixture.log`, `placement_preview.log`다.

- GLB 10개 헤더·해시·인덱스 삼각형 수 확인.
- 5곳 모두 저수지측 -Z 방향 확인.
- 축선 양 끝의 월드 좌표 변환 오차 최대 0.000489m. 이것은 좌표 변환의 수치 오차이며 원천 좌표 정확도가 아니다.
- 2단계 LOD 및 충돌 형상 확인, 맞춤 후 마루 중심의 물리 레이 충돌 확인.
- 동일 setup 재호출 시 중복 없음, 간몬 지도 및 범위 밖 소구역 배치 제외 확인.
- 현재 기준 DEM에서 읽은 국소 지형 패치 5개를 별도로 렌더링했다. 원본 고도 래스터 SHA256이 확인 전후 동일하다.
- 전체 게임에서의 접근·통행, 실제 지형 청크 LOD 전환, 기존 도로와의 접점, 프레임 성능은 확인하지 않았다. 실행 품질별 래스터와 철도 런타임 보정은 기준 래스터 프리뷰와 차이가 날 수 있다.
- 여수로·취수탑·관리동·수문 등 상세 부속시설은 미조사로 생성하지 않았다.
