# 철도 교량 에셋 제작 결과
범용 교량 5종과 안양교–울산역 연결 세트를 `godot_project/assets/generated/railway_bridges/`에 제작했다. 정적 SCN 파일 10개, 개별 미리보기, 비교 시트, 독립 프리뷰 실행파일과 재생성 파이프라인을 제공한다.

- 범용: 복선 콘크리트 박스거더, 단선 강판거더, 복선 강재 트러스, 복선 상로 아치, 복선 다경간 고가교.
- 연결 세트: 북측 접근부 235m → 안양교 아치 본체 231.8m → 울산역 방향 접근부 320m → 역 연결부 48m. 전체 834.8m.
- 안양교 본체는 상하행 병렬 상판, 3개 주아치, 주아치 위 소아치를 표현한다.
- 궤간 1.435m, 레일 상면 Y=0.12m, 궤도별 연결점과 가선, 난간, 상판 충돌을 제공한다.
- 모듈별 크기와 높이는 config/railway_bridge_assets.json에서 조정한다.
- 매니페스트에 해시, 로컬 AABB, 고도, 삼각형 수, 연결 규약과 모델 정확도를 기록했다.
- 커스텀 에셋 목록에 새 자산을 등록하고 양쪽 module_index.json을 갱신했다.

## 검증
기존 게임과 대형 맵을 실행하지 않고 임시 Godot 4.3 프로젝트에서 생성 및 저장·재로드했다. 10개 에셋의 연결점과 상판 충돌 형상을 확인했다. 조립 세트의 접속부 3곳에서 두 선로의 끝점 위치가 일치하는지 검사했다. 실제 OpenGL 프리뷰 렌더를 저장했고 최종 실행은 종료 코드 0이었다. 모델당 삼각형 수는 1,164~19,572개이며 조립 세트는 42,012개다.

## 정확도와 연결 범위
사용자가 확인한 안양교를 기준으로 [연구 논문](https://pmc.ncbi.nlm.nih.gov/articles/PMC5981442/)의 아치부 길이·중앙경간·높이와 구조적 특징을 반영했다. 상세 부재와 접근부 길이 배분, 높이, 방향은 제작 가정이다. 역 연결부는 외부 역 모델을 붙일 수 있는 궤도 접속부이며 울산역 전체 모델은 아니다. 기존 철도 운행 경로·월드 배치·역 정차 로직은 변경하지 않았다.
