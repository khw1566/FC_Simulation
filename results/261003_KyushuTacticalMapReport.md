# 큐슈 M키 지도 재생성

큐슈 맵이 칸몬 지도 이미지를 참조하던 설정을 전용 2048×2048 이미지로 교체했다. M키 전체 지도, 미니맵 및 선택 화면 미리보기가 같은 큐슈 전용 자산을 사용한다. 새 PNG는 약 0.3 MB이다.

- 범위: 북위 30.9–34.5도, 동경 129.5–132.0도. 플레이어 표시·지도 클릭 이동과 같은 바운딩 박스를 사용한다.
- [Natural Earth 공개 지리 자료](https://www.naturalearthdata.com/downloads/10m-cultural-vectors/)의 일본 해안선, 기존 공항 카탈로그 18곳, 수집된 칸몬 도로 1,157개를 같은 위경도 기준으로 합성했다.
- 공항명, 좌표 격자, 자료 출처와 생성일을 표기했다. 도로 범위는 칸몬 수집 구역으로 명시했다.
- 큐슈에 잘못 연결된 칸몬 행정경계를 제거하고 해당 탐색 탭을 비활성화했다. 다른 맵의 행정구역 탐색은 기존대로 유지한다.
- 두 자산 매니페스트에 이미지 해시·범위·고도·해상도를 기록하고 두 모듈 인덱스를 갱신했다.

실제 Godot HUD에서 M키 표시, 전용 경로, 미니맵 텍스처, 해상도, 행정경계 제거, 월드 범위, 확대, 중앙 클릭 이동 좌표의 8개 항목이 통과했다. 결과는 `261003_kyushu_map_hud_validation.json`, 화면은 `261003_kyushu_M_map.png`에 저장했다.

재생성 진입점은 `pipeline/processors/build_kyushu_tactical_map.gd`이다. Godot 프로젝트 경로를 지정하고 스크립트의 절대 경로로 실행한다. 해안선 입력은 `config/kyushu_coastline_source.geojson`에 보존했다.

새 지도는 실제 지리 해안선을 표시한다. 3D 큐슈 지형은 여전히 칸몬 래스터를 공유하는 임시 자료이므로 지도와 3D 해안선은 일치하지 않는다. 실제 광역 지형 및 전역 도로망 구축은 이번 지도 재생성에 포함되지 않는다.
