# 혼합 교차로·보행 데크 에셋 추가 보고
기존 도로·보행로 239종을 보존하고 독립 모델 109종을 추가했다. 전체 모델은 348종이다. 게임과 지도에는 적용하지 않았다.

## 추가 모델

| 구분 | 수량 | 구성 |
|---|---:|---|
| 교차로 중앙부 | 12 | 2·2, 4·2, 4·4, 6·2, 6·4, 8·4차선의 T자·십자 |
| 교차로 진입부 | 12 | 2·4·6·8차선, 아스팔트·콘크리트·블록 |
| 교차로 표시 | 16 | 중앙부별 횡단 표시 12종, 진입부별 차선 표시 4종 |
| 데크 표면 | 20 | 4개 소재·패턴, 3개 직선 폭, 45도·90도 곡선 |
| 데크 광장·분기 | 16 | 4개 소재의 6m·12m 광장과 T자·십자 분기 |
| 데크 경사로 | 3 | 폭 1.5·3·4.5m, 길이 12m, 높이 차 1m |
| 데크 난간 | 24 | 목재·강철·케이블, 직선·곡선·경사·광장 마감 |
| 데크 지지대 | 6 | 폭 3·4.5m, 높이 1.5·3·6m |

GLB와 대응 씬을 같은 에셋으로 센다. 추가 혼합 예제 씬은 모델 종류 수에 포함하지 않았다.

## 혼합 규격

- 교차로의 중앙부·진입부·횡단 표시를 분리했다. 진입부 소재와 표시를 교체할 수 있다.
- 중앙부의 각 포트는 주도로 또는 분기도로 차선 수를 기록한다. 진입부 바깥 포트는 같은 단면의 기존 일반 차도에 연결한다.
- 고속도로의 넓은 갓길 단면은 일반 진입부와 직접 일치하지 않는다.
- 데크와 기존 보행로는 폭과 표면 높이가 같은 walk 단면을 사용한다. 기본 표면 높이는 0.15m다.
- 광장 포트는 변 중앙의 폭 3m 개구부다. 남는 가장자리는 짧은 난간으로 마감한다.
- 데크 하부 프레임은 표면 모델에 포함된다. 난간·지지대는 별도 조립 모델이다.
- 경사 데크의 Start 높이는 0.15m, End 높이는 1.15m다. 상단 보행로 원점을 Y=1m 올려 연결한다.
- 곡선 난간과 경사 난간을 별도로 제공한다. 지지대 상단은 기본 프레임의 Y=-0.20m에 맞춘다.

## 혼합 예제와 지침

- `godot_project/assets/generated/road_assets/mixed_intersection_deck_demo.tscn`
- `godot_project/assets/generated/road_assets/MIXED_JUNCTION_DECK_GUIDE.md`
- `preview_mixed_junctions.png`, `preview_decks.png`, `preview_junction_deck_mix.png`

예제는 기존 아스팔트·콘크리트 차도, 턱 낮춤 모듈, 블록·석판·콘크리트 보행로를 새 교차로·데크와 연결한다. 직선·곡선·경사 난간과 지지대를 별도로 조립했다. 전체 맵이나 게임 실행 씬에 연결하지 않았다.

## 생성과 확인

- 확장 생성 명령: `.venv_campus/Scripts/python.exe pipeline/processors/road_assets/extensions.py`
- 기본 생성기도 확장을 다시 생성하도록 연결했다. 신규 모듈은 패키지와 두 모듈 인덱스에 등록했다.
- 대표 확장 씬 9개와 혼합 예제 1개를 Godot 4.3의 독립 확인 프로젝트에서 읽고 인스턴스를 생성했다. 10개 모두 통과했다.
- 확인용 복사·임포트·캐시는 `previews/asset_browser/junction_deck_check/`에 한정했다.
- 원본 프로젝트 임포터, 전체 맵, 에셋 브라우저 재빌드는 실행하지 않았다.
- 기존 모델·씬·게임 설정·도로 코드 504개 파일의 해시는 작업 전후 같았다.
- 전용 매니페스트 708개 항목의 파일 존재와 해시를 확인했다. 오류는 0개다.
- 신규·기존 도로 생성 모듈의 최대 길이는 170라인이다.
- 충돌체, 지형 밀착, 자동 배치, 주행과 경로 탐색은 포함하지 않았다. 이미지는 생성 메시의 경량 투영 결과다.

## 색인 갱신

- 기존 `road_assets` 분류를 유지하고 교차로·데크 메타데이터 규약을 지침과 분류 코드에 반영했다.
- 기존 항목을 보존하며 전용·공통 매니페스트와 카탈로그를 갱신했다.
- `.venv_campus/Scripts/python.exe pipeline/indexer/build_asset_index.py`를 수동 실행했다.
- 도로·보행로·교차로·데크 계열은 709개 파일이다. GLB 348개, 씬 350개, 메타데이터 2개, 이미지 7개, 문서 2개다.
- 전체 색인은 29,336개 파일이다. 보류 파일은 0개다.
