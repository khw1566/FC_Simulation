# 울산 80km 광역 맵 확장 및 행정구역 분류

## 생성 결과

- 맵 선택 목록에 `울산광역시 광역권 (80km x 80km)`를 추가했습니다.
- 기존 중심(위도 35.5445, 경도 129.2555)을 유지하고 동서남북 각각 10km를 확장했습니다.
- 면적은 3,600km²에서 6,400km²로 증가했습니다. 기존 60km 맵도 유지합니다.
- 경계: 남 35.1841, 북 35.9049, 서 128.81256666666667, 동 129.69843333333336.
- 지형·수계 5,632 × 5,632 픽셀, 고도 인코딩 -30~1,300m, 미리보기 640 × 640 픽셀입니다.

## 지형과 기존 자산

- 중앙 60km는 기존 울산 높이맵과 수계 마스크를 재표본화했습니다.
- 외곽은 보관된 140km 동남권 맵에서 지리 좌표에 맞춰 추출했습니다. 외곽 원본은 약 34m 간격이므로 출력 이미지 해상도가 실제 측량 상세도를 높이지는 않습니다.
- 기존 범위 바깥 1km 접합 구간에 부드러운 혼합을 적용했습니다.
- 80km 지형은 11 × 11 청크를 사용하여 기존 청크당 공간 해상도를 유지합니다.
- 기존 건물·도로 JSON과 인접 도로 보정 메타데이터를 공유합니다. 같은 중심과 좌표 비율로 월드 위치가 유지되며 기존 수집 캐시가 갱신되면 새 맵에도 반영됩니다.
- 울산공항 배치 파일과 공항 모델, 활주로·유도등을 공유하며 위경도로 배치합니다.
- 확장 영역의 건물·도로 신규 수집은 하지 않았습니다. 해당 영역은 지형·수계·행정구역이 제공되며, 상세 건물·도로 범위는 기존 수집분입니다. 신규 API 호출은 0회입니다.

## 행정구역

- 보관된 2026년 7월 경계 자료를 새 범위로 재처리했습니다. 시도와 시군구, 행정동 기반 읍면동, 법정리를 기존 HUD 계층에 연결했습니다.
- 시도 4개: 울산광역시, 부산광역시, 경상북도, 경상남도.
- 시군구 23개, 읍면동 203개, 법정리 582개 고유 코드가 포함됩니다.
- 섬 등 분리된 구성요소를 포함한 폴리곤 수는 총 814개입니다: 시도 4, 시군구 23, 읍면동 203, 리 584.
- 행정구역의 바운딩 박스만 걸치는 경우를 제외하도록 실제 다각형과 맵 사각형 교차를 계산합니다. 경계 형상은 기존 처리기의 약 35m 단순화를 사용하므로 측량용 정밀 경계가 아닙니다.
- 출처: 통계청 SGIS·행정안전부, mapcn-kr / vuski-admdongkor 보관 자료, CC BY 4.0. 원본 행정단위 코드와 이름을 유지합니다.
- 디버거는 기본적으로 80km 맵을 표시합니다. 주소 뒤에 `?map=ulsan_metro_60km`를 붙이면 기존 맵을 선택합니다.

## 파일 및 실행

- 설정: `config/ulsan_metro_80km.json`
- 자산: `godot_project/assets/maps/ulsan_metro_80km/`
- 행정구역 집계: 같은 폴더의 `administrative_summary.json`
- 생성기: `pipeline/processors/expand_ulsan_metro.py`
- 재생성: 지정 Python 실행 파일로 위 생성기를 직접 실행합니다.
- 맵별·전체 생성 자산 매니페스트에 SHA-256, 경계, 해상도, 고도 범위를 기록하고 양쪽 모듈 인덱스를 갱신했습니다.
- 자산 생성은 완료됐습니다. 이번 요청에서는 별도 게임 실행 테스트나 수동 비행 검사를 수행하지 않았습니다.
