# 철로 사전 보정 테스트맵

## 결과와 실행

울산 실제 지형 약 2.003km 정사각형 구역의 선로 22개 구간, 터널 5개 구간을 사용한 독립 테스트맵을 만들었다. 지형 세분화·높이 보정, 선로·침목·전차선·노반·터널 라이닝 및 충돌을 사전에 생성했다. 실행 시 선택한 지형 씬, 고정 지형 충돌 씬, 철도 씬 3개를 읽고 배치한다.

프로젝트 루트 `run_prebaked_rail_test.bat`를 실행하고 경량·표준·고품질을 선택한 뒤 테스트 시작을 누른다. 선로 가까이·터널 입구·전체 구역 버튼으로 이동할 수 있다. 우클릭으로 시점을 조작하고 WASD 이동, Q/E 하강·상승, Shift 빠르게 이동, Esc 마우스 해제, R 처음 위치 복귀를 사용한다.

독립 실행 프로젝트는 `results/prebaked_rail_test/runtime`이다. 실행 프로젝트에는 원본 고도, 철도 종단 JSON, 터널 마스크, 보정·메시 생성 스크립트가 없다. 기존 지도 선택 목록과 80km 월드 로딩 경로는 수정하지 않았다. 원본 프로젝트에서 에디터나 임포터를 실행하지 않았으며 테스트 프로젝트에서만 소구역을 실행했다.

## 사전 생성 내용

| 항목 | 경량 | 표준 | 고품질 |
|---|---:|---:|---:|
| 기본 그리드 | 32 | 64 | 128 |
| 보정 후 지형 삼각형 | 19,298 | 25,058 | 48,560 |
| 철로 주변 최대 세분화 간격 | 10m | 10m | 10m |
| 지형 충돌 | 같은 고품질 고정 자산 | 같은 자산 | 같은 자산 |

고정 지형 충돌은 터널 마스크에 해당하는 삼각형을 제외한 46,309개 삼각형이다. 궤도 상면과 터널 라이닝 충돌도 저장되어 있다. 품질 선택은 이미 만들어진 지형 메시를 선택하며 충돌을 재계산하지 않는다. 지형 표현의 기본 해상도가 달라도 선로 주변 보정 규칙과 궤도 위치, 이동 충돌체는 동일하다.

전체 씬 5개는 약 2.54MiB이며 경량 실행에서 읽는 3개 씬은 약 0.97MiB이다. 생성 단계는 약 3.43초가 걸렸다. 원본 래스터 추출, 외부 엔진 기동, 격리 임포트 시간은 생성 단계의 이 수치에 포함하지 않았다.

## 확인한 결과

- 경량·표준·고품질 모두 독립 프로젝트에서 로딩하고 궤도 충돌 높이 오차 0.2m 이내 검사에 통과했다. 씬 3개만 요청하며 실행 스크립트에는 지형 생성, 지형 보정, 노반 생성, 터널 마스크 검사가 없다.
- 경량 화면을 실제 Intel UHD Graphics / OpenGL Compatibility에서 렌더링하여 지형·선로·터널 표시와 한국어 안내를 확인했다.
- 첫 그래픽 확인: 자산 읽기·배치 148.1ms, 다음 화면 처리 프레임까지 1,872.3ms.
- 후속 그래픽 확인: 자산 읽기·배치 168.9ms, 다음 화면 처리 프레임까지 267.8ms. 최초 셰이더 준비 비용으로 실행마다 첫 화면 시간은 달라질 수 있다.
- 화면 없는 검사: 경량 187.4ms, 표준 181.4ms, 고품질 196.3ms. GPU 렌더링 시간이 빠져 있으므로 실제 첫 화면 시간으로 해석하지 않는다.
- 측정은 테스트 시작 이후이며 프로그램 기동 시간은 포함하지 않는다. 로딩 로그는 `results/prebaked_rail_test/render_light.log`, `render_final.log`, `smoke_light.log`, `smoke_standard.log`, `smoke_high.log`에 있다. 화면은 `results/prebaked_rail_test/runtime/capture.png`다.
- 격리 엔진의 인증서 저장소 경고와 화면 없는 렌더러의 종료 시 메시 해제 경고는 남았다. 생성 완료 표시, 씬 재로딩, 충돌 검사 및 실제 렌더링은 통과했고 GDScript 파싱 오류는 없었다.

## 범위와 후속 적용

터널 라이닝은 실제 중심선에 맞춘 간단한 연속 중공 단면이다. 원본 터널 모델의 모든 장식·입구 부재를 포함하는 완전한 복제는 아니다. 선로 침목·전차선·노반은 기존 생성기를 사전 실행했다. 전체 지도, 열차 운행, 건물·도로·수계는 이번 성능 측정 범위에 포함하지 않았다.

이번 결과는 작은 구역에서 사전 보정된 형상과 충돌을 읽기·배치만으로 실행할 수 있다는 확인이다. 80km 전체 성능 향상률이나 모든 장치의 동일한 로딩 시간을 보장하는 결과는 아니다. 전체 적용 시에는 품질별 지형 타일과 고정 충돌, 철도·터널 청크를 같은 방식으로 생성하고 가까운 타일부터 읽는 것이 다음 단계다. 엔진 버전 변경 시 해당 버전으로 재생성한다.
