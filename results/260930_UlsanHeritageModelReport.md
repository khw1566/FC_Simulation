# 울산왜성·언양읍성 커스텀 모델 구현

- 울산왜성: 불규칙 석축, 세 겹의 주요 성곽 윤곽, 남·동측으로 이어지는 석축 유구를 조립한 44,088삼각형 모델. 천수각은 만들지 않았다.
- 언양읍성: 약 375m 사각 윤곽, 남측 성벽·돌출 치성·옹성, 2층 개거식 영화루를 조립한 62,440삼각형 모델. 북·동·서측은 낮은 석축과 개구부로 표현했다.
- 영화루: 독립 목조 기둥, 주춧돌, 누마루, 난간, 기와 골과 처마가 있는 지붕, 뒤쪽 계단을 포함한다.
- 자료를 참고한 게임용 근사 모델이다. 현황 실측이나 정밀 복원 도면에 따른 모델은 아니며 성벽 윤곽, 잔존 높이, 문루 세부 치수는 추정값이다.

## 위치와 게임 통합

- 울산왜성 기준점: 북위 35.554522°, 동경 129.339582°(울산 중구 공식 학성공원 안내 좌표).
- 언양읍성 모델 중심: 북위 35.56815°, 동경 129.12278°. 울산시 안내의 북측 좌표 35.570001°, 129.122649°와 OSM 성벽 자료를 참고한 근사 중심이다.
- 해당 좌표가 지도 범위 안에 있을 때 게임 건물 관리자가 모델을 자동 배치한다. 60km·80km·140km 지도에서 두 모델의 로딩을 확인했다.
- 성벽 정점을 실제 지형 높이에 맞춘다. 영화루는 주변 지형 최고점을 기준으로 수평 배치하고 주춧돌 밑에 기초를 연장한다.
- 성벽·영화루와 중심점이 겹치는 일반 건물만 런타임에서 제외한다. 성 안의 일반 건물을 전체 삭제하지 않는다.
- F9 커스텀 오브젝트 열람 목록에서 '울산왜성', '언양읍성 · 영화루'를 선택할 수 있다.
- `previews/preview_ulsan_heritage.bat` 실행 후 1: 울산왜성, 2: 언양읍성, 3: 영화루. 마우스 드래그로 회전하고 휠로 확대한다.

## 검증

- Godot 4.3 실제 OpenGL 렌더러에서 60km·80km·140km 지도의 위치, 지형 접합, 성벽 충돌, 겹친 건물 제외 판정을 통과했다.
- 영화루 중앙 통로가 열려 있고 누마루가 충돌하는 것을 확인했다.
- 간몬 지도에서는 두 모델이 로딩되지 않는 것을 확인했다.
- 실제 게임 건물 관리자 스크립트의 구문 검사를 통과했다.
- 실제 80km 높이맵을 사용한 전용 미리보기에서 두 성곽과 영화루를 렌더링하여 확인했다. 전체 도시 건물과 함께하는 수동 비행 검수는 수행하지 않았다.
- 결과: `results/ulsan_heritage_validation.json`, 이미지: `ulsan_waeseong_preview.png`, `eonyang_eupseong_preview.png`, `eonyang_gate_preview.png`.
- 생성 자산은 `godot_project/assets/generated/heritage/`에 보관한다. 전역 자산 매니페스트에 SHA-256, BBox, 지표 기준 높이, 삼각형 수를 기록했고 양쪽 모듈 인덱스를 갱신했다.
