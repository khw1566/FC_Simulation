# 가속도 수준 최고속도 비례 5단계(20%~100%) 시스템 개편 및 구문 오류 해결 리포트

본 문서는 `building_road_manager.gd`의 식별자 미선언 스크립트 구문 오류 수정과, 비행 조작 시 가속도를 현재 기어의 최고속도에 비례하도록 5단계(20%, 40%, 60%, 80%, 100%) 비율 시스템으로 전면 개편한 내역을 기록합니다.

---

## 1. 스크립트 구문 오류(Parse Error) 즉각 해결

### 1) 오류 발생 원인
- `godot_project/scripts/terrain/building_road_manager.gd`의 `chunk_buildings` 루프 내부에서 `cx`, `cz` 변수가 사전 선언되지 않은 상태로 지형 높이 샘플링 호출문(`_sample_ground_height(cx, cz, base_y)`)에 전달되어 발생.

### 2) 수정 조치
- 루프 시작부에서 건물 중심 좌표 배열(`center`) 또는 다각형 정점들의 평균 중심값으로부터 `cx`, `cz`를 정확히 계산하여 로컬 변수로 명시적 선언.
- Godot `--check-only` 구문 검사를 통과하여 `Exit Code 0` 정상 로드 확인.

---

## 2. 최고속도 비례 5단계 가속도 시스템 개편

기존의 고정 수치(50, 150, 300, 500 m/s²) 프리셋 방식은 저속 기어(30m/s)에서는 지나치게 즉발적이고, 초극초음속 기어(마하 10, 3,400m/s)에서는 최고속도 도달까지 너무 오래 걸리는 불균형이 존재했습니다. 이를 현재 선택된 기어의 최고속도에 비례하는 5단계 비율 시스템으로 재설계했습니다.

### 1) 5단계 가속도 비율 및 도달 시간
- **1단계 (20%):** 5초에 걸쳐 최고속도에 도달하는 완만한 항공기 순항 가속
- **2단계 (40%):** 2.5초에 걸쳐 최고속도에 도달하는 표준 비행 기동
- **3단계 (60%):** 약 1.67초 만에 최고속도에 도달하는 고반응 전투기 기동 (기본값)
- **4단계 (80%):** 1.25초 만에 최고속도에 도달하는 급격한 로켓 가속
- **5단계 (100%):** 1.0초 만에 최고속도에 도달하는 초고반응 즉응 기동

### 2) 기어 연동 동적 가속도 계산 (`player_flight_controller.gd`)
```gdscript
func get_effective_acceleration() -> float:
    var max_spd: float = FLIGHT_GEAR_MAX_SPEEDS[flight_gear - 1]
    var pct: float = ACCEL_PERCENT_STEPS[current_accel_step]
    return maxf(max_spd * pct, 10.0)
```
- **기어 변경 시 자동 연동:** `Shift` 키로 기어를 전환하면 해당 기어의 최고속도에 맞추어 실제 가속도(m/s²)가 자동으로 재계산됩니다.
  - 예: 1단(30 m/s)일 때 60% = 18 m/s²
  - 예: 4단(600 m/s)일 때 60% = 360 m/s²
  - 예: 7단(3,400 m/s)일 때 60% = 2,040 m/s²
- **관성 감속도 동기화:** 최고속도에 비례하여 감속도 역시 `max_speed * 0.5` 수준으로 자동 보정되어, 초고속 비행 후 지나치게 미끄러지지 않고 자연스럽게 감속됩니다.
- **키 조작:** `Z` / `X` (또는 `[` / `]`) 키로 5단계를 실시간 순환 전환.

## 3. UI 및 도움말 갱신
- **Speed HUD:** 하단 기어 패널에 기어 및 동적으로 산출된 가속도(m/s²)를 실시간 표기.
- **F1 도움말 오버레이 (`help_overlay_hud_view.gd`):** 가속도 조작 설명을 "비행 가속도 5단계 조절 (최고속도의 20%, 40%, 60%, 80%, 100%)"로 최신화.
