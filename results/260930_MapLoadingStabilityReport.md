# 건물 표시 및 지도 로딩 수정

## 건물 미표시 원인과 수정

- 80km 지도 분할 자료의 실제 건물에 base_y=0이 기록되어 있다. 예: 웅촌로 1235-8, 웅촌로 1232-10.
- BuildingRoadManager가 base_y<=0.2인 건물을 메시 생성 전에 제외하고 있었다.
- 높이만으로 건물을 제외하는 조건을 제거했다. BuildingMeshBuilder는 기존 지형 샘플링 경로를 통해 실제 기초 높이를 결정한다.
- 원본 건물 자료와 분할 캐시의 내용은 이번 수정에서 변경하지 않았다.

## 로딩 안정화

- 대형 벡터 JSON을 공간별 작은 파일로 분할하고 주변 건물부터 순차 생성한다.
- 지형 생성 및 도로 생성을 프레임에 분산하고 이미지 읽기를 별도 작업으로 처리한다.
- 실제 준비 상태를 표시하고 중복 로딩 차단, 실패 안내, 메뉴 복귀, 취소 후 정리를 적용했다.
- 80km, 60km, 140km 분할 캐시를 생성했다.

## 확인 범위

- 건물 제외 조건 수정 전에 수행된 80km 로딩 실행 기록: 28.828초, 최장 프레임 685ms, 중복 요청 차단 및 메뉴 복귀와 취소 복구 성공.
- 위 시간은 건물 제외 조건 제거 이전 수치이므로 수정 후 성능을 나타내지 않는다.
- 건물 표시 수정 후 게임 실행 및 화면 검증은 수행하지 않았다. 실제 건물 생성량 증가에 따른 로딩 시간과 표시 상태는 추가 확인이 필요하다.
- 이미 실행 중인 게임에는 파일 수정이 반영되지 않으므로 재시작이 필요하다.
