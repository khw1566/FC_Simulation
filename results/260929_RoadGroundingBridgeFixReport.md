# 도로 지형 겹침 및 교량 밀집 개선

## 확인한 원인

- 도로 높이는 원본 높이맵 보간값으로 계산했지만 화면 지형은 청크별 LOD 삼각형으로 만들어져 두 표면이 달랐습니다.
- 도로 선분 내부가 지형 삼각형 경계를 가로지르면 양끝의 높이만 맞춰도 중간이 묻힐 수 있었습니다.
- 수계 마스크가 0.15 이상이거나 지형 고도가 1m 미만이면 교량으로 분류하고, 정점 두 개씩 육지 쪽으로 확장하던 조건이 있었습니다.
- 교량은 선분별로 상판 방향을 계산해 곡선 이음매가 겹쳤고, 조각의 첫 정점마다 교각을 만들었습니다. 교각 전체 폭은 도로 폭의 약 70%였습니다.
- 광역 도로 수집 결과는 일방통행·차로 수·실제 폭 정보를 생략하고 도로 종류별 고정 폭만 기록했습니다.

## 수정 내용

- 일반 도로 표면을 지형 LOD0 격자선과 대각선에서 분할했습니다. 상위 LOD의 경계도 포함되므로 도로 삼각형이 지형의 꺾임을 가로지르지 않도록 합니다.
- 도로 셰이더가 실제 청크 LOD, 동일한 높이맵 픽셀 범위와 삼각형 보간을 사용합니다. 지형 LOD가 바뀌면 작은 상태 텍스처만 갱신하고 도로는 지형 위 1.2m로 따라갑니다.
- 도로 옆면도 경계에서 분할하고, 셰이더 변위에 맞춘 컬링 범위를 적용했습니다.
- 저고도만으로 교량을 생성하는 조건을 제거했습니다. 명시적 터널·교량 태그를 우선하며 태그 없는 자동 교량은 양안이 확인되고 강한 수계가 24m 이상 이어질 때로 제한했습니다.
- 이전 `is_bridge`·`is_tunnel` 필드와 문자열 `no`도 올바르게 처리합니다.
- 동일한 좌표·높이·폭·층·분류의 도로는 역방향 배열까지 포함해 한 번만 렌더링합니다. 일부만 겹치는 도로나 서로 다른 층의 도로를 무조건 병합하지 않습니다.
- 교량 상판의 이음매 좌표를 공유하고, 실제 누적 길이로 종단을 계산합니다.
- 교각은 누적 거리 약 40m 간격으로 배치하며 시작점 강제 교각을 제거했습니다. 교각 반폭은 도로 폭의 10%, 최소 0.6m·최대 2.2m로 제한했습니다.
- 광역 데이터의 터널 Y=0은 미지정 값이므로 양 입구 지형 높이를 이용해 연결합니다.

## 실제 도로 속성 복원

- 대상: 울산 60km 도로 8,878개, 기존 명시적 교량 태그 1,664개, 터널 태그 269개.
- 보관된 `data/raw/ulsan_metro_60km/highways/overpass_ulsan_metro_highways.json`을 사용해 8,878개 전체의 좌표를 대조했습니다. 새 네트워크 수집은 하지 않았습니다.
- `width` 태그를 우선하고, 없으면 차로 수×3.5m+여유 폭 1.5m로 추정합니다. 둘 다 없는 일방통행은 기존 도로 폭의 55%, 최소 4m를 적용합니다.
- 폭이 변경된 도로: 5,813개. 차로 수·일방통행 기반 폭은 실측값이 아닌 렌더링 추정값입니다.
- `road_metadata.json`에 폭 근거·OSM ID·층·좌표 해시를 별도로 보존합니다. 이후 도로 데이터의 좌표가 바뀌면 이전 보정값을 적용하지 않습니다.
- 자료 출처: OpenStreetMap contributors, ODbL. 원본 도로·건물 통합 JSON은 수정하지 않았습니다.

## 확인 결과와 범위

- 총 15개 회귀 검사 통과: LOD 0/1/2 동기화, 교량·터널 분류, 문자열·이전 필드 지원, 역방향 중복과 층 보존, 중복 정점 제거, 짧은 교량 교각, 지형 분할 면적 보존, 실제 속성 연결과 좌표 불일치 방어.
- OpenGL 렌더러에서 기복이 큰 시험 지형의 세 LOD 이미지를 생성하고 시각 확인했습니다.
- 결과: `results/road_render_validation.json`, `results/road_lod_0.png`부터 `road_lod_2.png`.
- 실제 도로 8,878개의 속성 연결은 검증했으나 전체 60km 맵의 모든 교량을 수동 비행하거나 프레임 성능을 측정하지는 않았습니다.
- 도로 표면 처리는 시각 메시 변경입니다. 차량 주행용 정밀 도로 충돌체를 새로 추가한 작업은 아닙니다.
- 원본에 차로·폭·층 정보가 없는 일부 고가도로의 실제 구조와 높이 관계에는 근사가 남습니다.
- 모듈 인덱스 및 도로 보정 자산의 해시·경계·고도 범위·레코드 해상도 매니페스트를 갱신했습니다.

```powershell
& '.\tools\godot\Godot_v4.3-stable_win64_console.exe' --headless --path godot_project --script (Join-Path (Get-Location) 'pipeline/processors/restore_road_metadata.gd')
```
