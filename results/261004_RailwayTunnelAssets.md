# 범용 철로 터널 에셋 제작 결과
고속철도용과 동해선용 복선 터널을 `godot_project/assets/generated/railway_tunnels/`에 제작했다. 각 형식의 입구·내부·출구·조립 완료 씬 4개씩과 내부 구조 확인용 씬 2개를 제공한다.

- 고속철도용: 넓은 단면과 확폭 갱구, 슬래브 궤도, 64m 조립 세트.
- 동해선용: 상대적으로 작은 단면과 콘크리트 갱구, 자갈 궤도, 52m 조립 세트.
- 양측 보행로, 배수로, 케이블 트레이, 가선·지지 부재, 표시등·발광 조명을 포함한다.
- 입구와 출구의 가운데가 열린 중공 라이닝이며 벽·천장·바닥·보행로·도상의 충돌 형상을 제공한다.
- 궤간은 1.435m, 레일 상면 Y=0.12m로 기존 철도 에셋 규약에 맞췄다. 선간 중심 거리는 고속철도용 5.4m, 동해선용 4.4m다.
- 조립 시 라이닝 단면 및 두 선로 연결점을 검사했다. Godot 4.3의 생성·저장·재로드와 4개 대표 구도의 실제 렌더를 경량 고유 프로젝트에서 수행했다.
- 대형 맵, 원본 에디터·임포터, 실행 중인 게임 및 다른 프리뷰 프로세스는 실행하거나 종료하지 않았다.
- 원본 에셋만 추가했으며 전체 에셋 프리뷰 실행기는 재빌드하지 않았다. 렌더 이미지·임시 캐시는 프리뷰 전용 경로에 저장했다.
- 자산 생성의 공용 매니페스트와 모듈 인덱스를 갱신했다. 프리뷰 모듈은 전용 디렉터리의 module_index.json에 등록했다.

## 사용 범위
특정 실제 터널의 측량 모델이 아닌 게임용 범용 에셋이다. 기존 services.json의 고속철도 슬래브·동해선 자갈 도상 구분을 반영했다. 실제 지형 배치·터널 굴착·열차 경로·실시간 조명은 포함하지 않는다. 사용 및 재생성 방법은 에셋 폴더의 README.md에 기록했다.
