# 울주군 서부 Phase 5 건물 수집 진행 상황

## 권역 및 제한 관리

- 언양·KTX울산역·범서 중심으로 35.4800°~35.6400°N, 129.0700°~129.2300°E를 6×5, 총 30셀로 나눴습니다.
- 셀마다 약 2.9km × 3.0km로, 약 8.7km²입니다. 요청 면적 10km² 미만 조건에 들어갑니다.
- API 하루 상한은 700회로 제한했습니다. 작업 전 당일 매니페스트 누계 173회에서 시작했습니다.

## 결과

- Phase 5 셀 15/30 완료, 고유 건물관리번호 총 113,857개입니다.
- 런타임 건물 113,562동을 생성했고, 기존 도로·터널은 보존했습니다.
- 누적 VWorld 요청은 329회입니다. 700회 상한까지 371회가 남았지만, 이 값은 프로젝트 매니페스트가 기록하는 요청 수 기준이며 VWorld 계정의 실시간 한도 화면에서 조회한 값은 아닙니다.
- y3_x0 셀을 재개하는 중 두 번 응답 시간이 초과됐습니다. 요청은 오류 시 중지되도록 동작했고 해당 셀은 완료 목록에 넣지 않았습니다. 다른 API 일일 한도 오류나 HTTP 429는 확인되지 않았습니다.
- 호출 상한에 도달하기 전에 반복 시간 초과로 오늘 요청을 멈췄습니다. 같은 호출 장애가 반복되는 상태에서 더 요청하지 않았습니다.

## 맵 반영

- 성공적으로 완료된 Phase 1~4와 Phase 5의 15개 셀 캐시를 병합했습니다.
- 병합 결과는 60km 맵 `buildings_and_roads.json`이며, 새 건물 높이 계산에 해안 후보정 높이맵과 새 통합 수계 마스크를 사용했습니다.
- 80km 맵은 이 60km 런타임 도로·건물 자료를 공유합니다. 새로 추가된 범위 밖 상세자료를 수집한 것은 아닙니다.
- 매니페스트의 오늘 완료 Phase 5 셀과 요청 오류를 유지해 미완료 셀을 이어서 수집할 수 있습니다.
- API 실패, 쿼터 잔여량의 외부 검증은 수행하지 않았고, 게임 렌더 실행 확인도 하지 않았습니다.
