# 공단 마스킹과 절차 생성 계획

현재 범위는 울산광역시 80km 지도다. 사용자가 지정한 공단 경계 안에 게임용 도로와 산업 설비를 생성한다. 이번 작업에서는 경계 편집기와 1차 마스크 생성 구조를 마련한다. 도로 및 산업 에셋의 월드 배치는 후속 작업이다.

## 1. 구역 지정부터 시작

- 기존 로컬 자료에는 공단 확정 경계가 없다. `config/industrial_zones.geojson`은 빈 FeatureCollection으로 시작한다.
- `previews/industrial_zone_editor/editor.html`을 브라우저에서 열고 지도를 확대해 공단 외곽을 다각형으로 지정한다. 제조·석유화학·조선·물류 유형과 초안/확정 상태를 선택한다.
- 각 구역에는 중복 없는 `zone_id`, 이름, 생성 프로필, 고정 seed를 기록한다. 경계는 WGS84 경도·위도로 저장한다.
- 수계와 주변 주거지를 가로지르는 넓은 사각형 대신 실제로 생성할 육지 영역을 따라 경계를 그린다. 떨어진 부지는 여러 구역으로 나누고, 보호 영역은 GeoJSON 내부 링으로 제외할 수 있다. 편집기는 내부 링을 불러와 표시하며 새 내부 링 그리기는 아직 지원하지 않는다.
- 초안은 도형 확인용이며 생성 허용 마스크에는 포함하지 않는다. 확정 구역만 후속 생성 대상이다.
- 편집기에서 GeoJSON을 저장한 뒤 `config/industrial_zones.geojson`을 교체한다. 원본 지도와 에셋은 편집하지 않는다.

## 2. 1차 마스크 생성

```powershell
& '.venv_campus/Scripts/python.exe' pipeline/processors/industrial_zones/build_masks.py
& '.venv_campus/Scripts/python.exe' pipeline/indexer/build_asset_index.py
```

- 출력 경로: `godot_project/assets/generated/industrial_zones/ulsan_metro_80km/`.
- `zone_ids.png`: 16bit 구역 번호. 0은 구역 밖, 1~65535는 개별 공단.
- `excluded_water.png`: 기존 수계 마스크와 20m 여유 영역을 제외한다.
- `allowed.png`: 확정 구역에서 수계를 제외한 1차 허용 영역. 모든 배치가 안전하다는 최종 판정으로 사용하지 않는다.
- `regions.json`: 구역별 유형·seed·상태와 원본 해시, 생성 허용 픽셀 수를 기록한다.
- 초기 해상도는 4096², 약 19.53m/픽셀이다. 소규모 부지의 정밀 배치는 원본 다각형을 직접 사용한다. 마스크 하나로 좁은 도로나 개별 설비의 충돌을 판정하지 않는다.
- 구역 중복·지도 밖 좌표·닫히지 않은 외곽선·중복 ID를 거부한다. 자기 교차 다각형의 정밀 기하 검사는 다음 단계에 추가한다.
- 현재 경계가 비어 있으므로 구역·허용 마스크는 비어 있다. 수계 제외 마스크만 실제 지도로 생성한다.

## 3. 배치 제외 영역 보강

후속 도로 생성 전에 기존 도로, 철도, 철도교·터널, 하천·바다·호수, 공항, 문화유산 및 보존 건물의 실제 점유 형상을 합쳐 제외 마스크를 만든다. 도로는 통행 폭과 여유 폭, 철도는 궤도와 가선 공간을 포함한다. 경사·고저 차 조건도 추가한다. 기울어진 지형에서는 배치 후보를 거부하거나 작은 독립 기초를 사용하며 광범위한 지형 절삭은 피한다.

기존 건물은 처음에는 모두 보존한다. 교체할 건물이 필요하면 대상 ID 목록을 별도로 정하고 새 배치 결과를 검토한 뒤 반영한다. 단순히 구역 안에 있다는 이유로 기존 건물을 제거하지 않는다.

## 4. 공단 내부 도로망 생성

- 공단별 주축 방향과 외부 진입점을 지정한다. 무작위로 연결점을 만들지 않고 기존 도로의 접속 가능한 위치를 선택한다.
- 제조·물류는 격자 또는 약간 변형된 직교 도로, 석유화학은 큰 블록과 순환 도로, 조선은 해안선에 평행한 장축과 대형 운송 통로를 사용한다.
- `config/industrial_zones.json`의 블록 크기, 주도로·내부 도로 폭은 초기 조정값이다. 고정 seed로 방향·간격을 조금씩 변화시켜 같은 구역은 재생성해도 동일하게 만든다.
- 경계와 제외 영역으로 도로를 잘라 연결 그래프를 만든다. 짧은 막다른 조각, 급한 곡선, 단절 구간을 제거하고 모든 사용할 블록이 진입점에 연결되는지 확인한다.
- 철도·수계 횡단이 필요한 후보는 우회한다. 교량이나 건널목은 별도 설계 대상으로 기록한다.
- 도로 메시보다 먼저 선형과 폭이 담긴 `roads.json` 및 2D 검토 이미지를 출력한다.

## 5. 필지와 산업 에셋 배치

- 도로 사이 공간을 필지로 분할하고 도로에서 일정 거리 물린 배치 영역을 만든다. 모든 필지는 차량 접근 통로를 갖도록 한다.
- 기존 `industrial/catalog.json`의 실제 footprint, AABB, padding, scale 범위를 사용한다. 산업 플랜트 계열의 연결 포트와 야간 조명 리그도 사용 여부를 명시한다.
- 일반 제조: 공장·창고를 주로 배치하고 연통·냉각 설비를 부속으로 둔다.
- 석유화학: 저장탱크 군집, 증류탑, 연통, 냉각 설비를 공정 단위로 묶고 배관은 포트 사이에서 연결한다.
- 조선: 대형 격납고와 크레인 중심으로 구성하고 해안측 작업장·진입 공간을 비워 둔다.
- 물류: 창고·야적장·주차·회차 공간 중심으로 구성한다. 빈 공간도 배치 계획의 일부로 보존한다.
- 에셋을 회전·축척한 뒤 전체 footprint가 필지 안에 있는지, 다른 에셋·도로·제외 영역과 겹치지 않는지 확인한다. 중심점만으로 판정하지 않는다.
- 건물 모서리별 지표를 조회해 고저 차를 검사한다. 허용 차이를 넘으면 다른 후보를 선택하고, 배치 가능한 경우 지표까지 이어지는 기초를 생성한다.
- 배치 결과는 모델 원본을 수정하지 않는 `placements.json`으로 출력한다.

## 6. 모듈과 월드 통합 순서

- `industrial_zones/build_masks.py`: 수동 경계의 마스크 변환. 이번 단계 구현.
- 후속 `exclusions.py`: 기존 시설과 경사를 이용한 배치 제외 영역.
- 후속 `road_graph.py`: 연결 가능한 내부 도로 그래프.
- 후속 `parcel_builder.py`: 도로 기준 필지 분할.
- 후속 `asset_placer.py`: 프로필별 배치 및 footprint 검사.
- 후속 Godot `IndustrialZoneManager`: 승인된 배치 데이터 로드와 청크별 거리 표시.
- 검토 단계에서는 원본 월드와 별개로 한 구역만 표시한다. 이후 작은 공단 한 곳부터 통합하고 범위를 넓힌다.
- 멀리서는 합친 저품질 메시, 가까이서는 상세 에셋을 사용한다. 배관·소형 부속·야간 광원은 표시 거리와 수량을 따로 제한한다.
- 기존 실제 도로와 생성 도로가 중복되지 않도록 접속부·점유 범위를 관리한다. 절차 공단 표시 설정을 끄면 기존 지도 상태로 돌아갈 수 있도록 별도 관리한다.

## 다음 실행 순서

- 편집기에서 작은 공단 한 곳을 초안으로 지정하고 지형·수계·기존 시설 경계를 검토한다.
- 확정 후 마스크를 다시 생성한다.
- 기존 시설 제외 영역을 보강하고 2D 도로 그래프를 생성한다.
- 한 구역의 필지와 에셋 배치 결과를 검토한 뒤 독립 3D 구역으로 확인한다.
- 마지막으로 월드에 연결한다. 이번 단계에서는 월드 로딩과 도로·에셋 배치를 수행하지 않는다.

## 이번 기초 작업 결과

- 구역 편집기, 빈 경계 GeoJSON, 유형별 설정, 마스크 생성기를 작성했다.
- 4096² 마스크 생성 완료. 구역 ID는 16bit이며 수계 제외 마스크는 0~255다. 확정 구역이 없어 구역 ID와 허용 마스크는 전부 0이다.
- 마스크·카탈로그 해시와 bbox·해상도를 전용 및 공통 매니페스트에 기록했다. 고도는 미확인으로 null이다.
- 새 계열을 에셋 분류 지침과 분류 코드에 등록하고 양쪽 모듈 인덱스를 갱신했다.
- 전체 에셋 색인 수동 갱신 완료: 23,215개 파일, 보류 0개. 전체 맵은 실행하지 않았다. 편집기의 실제 브라우저 조작은 미검증이다.

## 계획 실행 완료
사용자의 자동 후보 지정에 따라 본항·온산항 주변 두 구역을 확정했다. 안전 영역, 연결 도로, 필지, 설비 및 배관 배치와 월드·설정 연동을 구현했다. 설비 43개, 부착 배관 랙 7개, 도로 12개, 필지 20개를 생성했다. 기초 단계의 빈 경계와 비활성 상태는 현재 산출물에 해당하지 않는다. 최종 구현 및 확인 범위는 `results/261004_IndustrialImplementation.md`에 기록했다.
