# 에셋 프리뷰 자동 최신화

`previews/asset_browser/AssetPreview.exe`를 자동 최신화 실행기로 교체했다. 실행 중 원본의 추가·수정·삭제를 3초 간격으로 확인하며, 안정된 파일을 복사하고 임포트한 뒤 목록과 선택된 프리뷰를 갱신한다. 복사·임포트 시간이 확인 간격에 추가된다.

- 원본 `godot_project`는 읽기 전용이며 원본 프로젝트에서 임포터, 지도 또는 게임을 실행하지 않는다.
- 프리뷰 캐시와 임포트 공간을 분리하고 단일 작성자 잠금, 원자적 파일 교체, 쓰기 중 파일 보류, 미완료 갱신 재시도를 적용했다.
- Windows 실행기는 별도의 Python 설치 없이 동작한다. 프리뷰 폴더의 `runtime`, `project`, `live_settings.json`을 함께 유지한다.
- 기존 3D 파일 및 생성 모델 53개, 이미지 80개의 열람을 새 실행기로 확인했다.
- 별도 소형 원본에서 신규 GLB·이미지·씬·데이터 추가, 선택된 씬의 치수 변경, 이미지의 색과 해상도 변경, 씬 삭제가 실행 중인 UI에 반영됨을 확인했다.
- 해당 테스트 원본의 내용 해시가 동기화 전후 동일했으며 원본 `.godot`와 `.import`가 생성되지 않았다.
- 관련 원칙과 경로를 `AGENTS.md` 6절에 기록했다.
- 상세 검증 결과는 `previews/asset_browser/live_verification.json`에 보관했다.
