# 철로 및 열차 야간 식별 조명

열차 생성기와 철로 생성기에 공통 조명 모듈을 적용했다. KTX·동해선은 흰색 전조등, 붉은 후미등, 객실 발광, 원거리 식별 표시를 포함한다. 객차의 자식으로 조명을 추가하여 운행 서비스가 사용하는 객차 수를 보존한다.

- 철로 좌우 교대 120m 간격 식별 표시와 300m 간격 근거리 광원.
- 기존 철도교 10개 SCN과 터널 10개 SCN 재생성. 열차·철로·조립 예제 6개 SCN 추가.
- 실제 광원은 그림자를 끄고 카메라 거리 페이드 적용. 전조등 조사 범위 110m, 철로 광원 범위 6m.
- 원거리 표시는 깊이 가림을 유지하는 고정 화면 크기 빌보드로 구현. 낮에도 유지하며 실제 설비 배치가 아닌 게임용 시각 보조다.
- 공용 매니페스트는 비대상 항목을 보존하며 원자적 교체. 신규 모듈은 양쪽 모듈 인덱스에 등록.
- 독립 경량 프로젝트에서 Godot 4.3 Compatibility 생성 및 1280×720 야간 렌더 성공. KTX·동해선·철로 약 1.5km 표시를 이미지로 확인.
- 전체 맵 실행과 프리뷰 실행파일 재빌드는 수행하지 않았다. 전체 맵의 지형·안개·운행 중 결과와 대규모 노선 성능은 미확인이다.

색인 완료: 23,210개 파일, pending 0. 추가 및 재생성 SCN 26개의 실제 파일 SHA256을 개별 매니페스트와 대조했다.

철로 과잉 표시 수정: 식별 표시 크기 5에서 2로 축소, 색상과 불투명도 감소. 양측 50m 반복을 좌우 교대 120m로 변경. 520m 예제 표시 수 22개에서 5개로 감소. 실제 광원 에너지 1.2에서 0.35, 간격 150m에서 300m, 범위 10m에서 6m로 조정. 열차 조명 설정은 유지했다. 수정 후 독립 야간 렌더와 생성 완료.
