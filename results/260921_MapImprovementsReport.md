# [260921] 지도 기능 개선 및 시야각(FOV) 콘 렌더링 완료 리포트

- 작성일자: 2026년 09월 21일
- 작성자: Antigravity AI

---

## 1. 개선 개요
- 지도(전체 화면 및 미니맵) 조작성 향상과 탐색 시인성 극대화를 위해 마우스 지점 기준 줌, UI 편의 버튼, 그리고 플레이어의 동적 시야 방향 및 시야각(FOV) 시각화 기능을 구현 완료함.

---

## 2. 세부 구현 사항

### A. 마우스 커서 위치 기준 줌 (Mouse-Centered Zoom)
- 기존: 대형 지도의 고정 원점(좌상단/중앙)을 기준으로 확대/축소되어 사용자가 원하는 관심 지점이 화면 밖으로 밀려나는 문제 발생.
- 개선: 마우스 휠 이벤트 발생 위치(`event.position`)를 앵커 포인트로 고정하고, `_map_offset = mouse_pos - (mouse_pos - _map_offset) * (new_zoom / old_zoom)` 수학적 변환 공식을 적용하여 마우스 커서가 가리키는 지도 상의 지점이 정확히 확대/축소 중심을 유지하도록 구현.

### B. 지도 제어 편의 버튼 구현
- **플레이어 중심 (Recenter) 버튼:** 현재 플레이어의 월드 좌표를 역투영하여 맵의 중앙(`clip_center`)에 즉각 정렬.
- **지도 원위치 (Reset) 버튼:** 줌 레벨을 기본값(1.0x)으로 복원하고 지도 패닝 오프셋을 초기화.

### C. 시야 방향 및 시야각(FOV Cone) 반투명 렌더링
- **`MapFovDrawer` (`map_fov_drawer.gd`):**
  - 단일 책임 원칙(SRP)에 따라 독립된 CanvasItem 렌더링 모듈로 신설.
  - 플레이어 카메라의 `fov`(기본 70° ~ 고속 순항 시 최대 115°)와 3D Yaw 회전 각도를 실시간 전달받음.
  - 모노크롬 기본 테마 규격에 맞춘 반투명 화이트(Fill: `rgba(1, 1, 1, 0.15)`, Edge: `rgba(1, 1, 1, 0.45)`) 부채꼴 원추(Cone)를 16개 세그먼트 폴리곤으로 드로잉.
  - **미니맵과 대형 지도 양쪽에 동시 적용**되어 현재 바라보는 방향과 시야 범위를 직관적으로 파악 가능.

## 3. 관련 소스 코드 파일 인덱스

| 파일 경로 | 역할 및 책임 |
