# 철로 주변 실제 지형 보정

- 공단 작업에 앞서 첨부 화면의 철로 매몰 문제를 처리했다.
- 원인: 세밀한 철도 종단과 표시 지형의 LOD 삼각형 간 높이 불일치. 울산 80km의 11×11 청크는 LOD별 약 57m·114m·227m 간격으로 지형을 표시한다. 높이맵에만 좁은 보정을 적용하면 큰 삼각형이 선로를 덮는다. 도로는 표시 삼각형 높이를 따르는 셰이더를 사용하지만, 철도 종단을 그대로 지표에 붙이면 열차의 수직 굴곡이 심해질 수 있다.
- 해결: 표시 지형을 철도 종단에 맞춰 국소 절토한다. 선로와 열차의 종단을 LOD 높이로 이동시키지 않는다.
- 새 RailwayTerrainGrader는 일반 철로의 경로만 공간 색인한다. 교량·터널 경로는 보정에서 제외한다.
- 철로 주변 삼각형만 최대 변 길이 10m까지 세분화한다. 중심에서 12m 이내는 종단 높이 아래 0.65m를 상한으로 삼고, 바깥 16m는 부드러운 가중치로 기존 지형에 연결한다. 이미 낮은 지표는 다시 올리지 않는다.
- 삼각형을 삭제하지 않으므로 지형에 구멍을 만들지 않는다. 기존 터널 개구부 처리는 유지한다.
- 각 지형 LOD와 메시 캐시에 보정을 적용한다. 충돌체는 보정 메시에서 생성하며 지표 높이 조회도 같은 보정 함수를 사용한다. 기존 원본 높이맵과 모델 자산은 수정하지 않았다.
- 모듈을 양쪽 module_index.json에 등록했다.
- 확인: TerrainChunkManager 문법과 의존성 검사 통과. 128m 독립 지형 조각의 세 가지 격자 간격에서 실제 삼각형 높이 459개 지점 검사 통과. 선로 양쪽 바닥 여유, 빈 구멍 부재, 철로 밖 높이 보존, 교량·터널 제외 확인. 최종 검사 메시 총 정점 16,272개.
- 전체 맵 실행, 첨부 좌표에서의 실제 화면, 장시간 LOD 전환과 전체 로딩 성능은 미검증이다. 국소 세분화에 따른 지형 메시 증가가 있으므로 실제 맵에서 성능을 확인해야 한다.
- 이번 변경은 코드와 문서만 추가·수정했다. 에셋 추가·수정은 없어 에셋 색인 재생성은 수행하지 않았다.
