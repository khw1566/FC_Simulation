# 맵별 랜드마크 태그 격리

선택 맵의 랜드마크 파일이 비었거나 누락됐을 때 칸몬 자료를 대체 로드하던 코드를 수정했다. 맵이 선택됐으면 해당 자료만 사용하고, 범위 밖 좌표를 제외한다. 재로드 시 기존 태그도 정리한다.

경량 논리 검사 6개 통과: 빈 경로, 없는 파일, 범위 밖 좌표, 칸몬 정상 태그 유지, 재로드 중복 방지, 기존 태그 정리. 검사 종료 시 독립 Godot 환경에서 렌더러 캐시 저장 오류가 발생했으므로 실행 전체를 무오류 검증으로 보지는 않는다. 전체 지도 화면 검증은 생략했다. 에셋 파일은 수정하지 않았다.
