# 철로 사전 보정 테스트 자산

울산 80km 원본의 약 2,003m 정사각형 구역을 추출한 독립 테스트맵이다. 실제 선로 22개 구간과 터널 중심선 5개 구간을 사용한다. 구역 경계의 선분을 잘라 영역 밖 선로를 연결하지 않는다.

- `terrain_light.scn`, `terrain_standard.scn`, `terrain_high.scn`: 32/64/128 기본 그리드에 철로 주변 10m 세분화와 노반 아래 고도 보정을 모두 적용한 지형 메시.
- `collision.scn`: 고품질 지형에서 터널 마스크에 해당하는 충돌 삼각형을 제외하여 저장한 고정 충돌체. 품질 선택에 관계없이 동일한 파일을 사용한다.
- `railway.scn`: 완성된 선로·침목·전차선·노반·터널 라이닝, 궤도 상면 및 터널 충돌체. 생성 스크립트는 씬에 포함하지 않는다.
- `catalog.json`: 원본 및 생성기 해시, 실제 구역 bbox, 초기 시점, 충돌 확인 위치, 생성 통계.
- `manifest.json`: 각 씬의 해시, 크기, bbox, 고도 인코딩 범위, 원본 추출 해상도, 품질 해상도, Godot 버전.

## 실행

프로젝트 루트의 `run_prebaked_rail_test.bat`를 실행한다. 시작 전 경량·표준·고품질을 선택한다. 준비 화면의 시간은 시작 버튼 이후 자산 읽기·배치 및 첫 처리 프레임까지이며 프로그램 자체 기동 시간은 포함하지 않는다.

선로 가까이·터널 입구·전체 구역 버튼으로 시점을 바꿀 수 있다. 우클릭으로 시점 조작을 시작하고 WASD로 이동, Q/E로 하강/상승, Shift로 빠르게 이동한다. Esc는 마우스 해제, R은 처음 위치 복귀다.

실행 프로젝트는 `results/prebaked_rail_test/runtime`에 별도로 구성되며 Compatibility 렌더러를 사용한다. 원본 프로젝트의 임포트 캐시나 지도 선택 목록은 변경하지 않는다. 원본 DEM, 철도 종단 JSON, 터널 마스크, 메시 생성기는 실행 프로젝트에 포함하지 않는다.

## 재생성

```powershell
& '.\.venv_campus\Scripts\python.exe' pipeline/processors/build_prebaked_rail_test.py
& '.\.venv_campus\Scripts\python.exe' pipeline/indexer/build_asset_index.py
```

재생성은 원본의 변경 여부와 전용 작성자 잠금을 확인하고 `results/prebaked_rail_test/bake_project`에서 수행한다. 실행 중 자동 재생성하지 않는다. Godot 4.3의 네이티브 씬 형식이며 다른 엔진 버전으로 배포할 때는 해당 버전으로 다시 생성해야 한다.

## 범위

철로 주변 지형 보정과 사전 생성 자산의 읽기·배치를 비교하는 소구역 시험이다. 터널은 실제 중심선에 맞춘 간단한 연속 라이닝을 사용하며 원본 터널 모델의 모든 장식과 입구 부재를 재현하지 않는다. 전체 80km 지형, 열차 운행, 건물·도로·수계 전체 장면의 성능 검증 결과로 해석하지 않는다. 그래픽 드라이버의 최초 셰이더 준비 시간과 장치별 파일 읽기 비용은 남는다.
