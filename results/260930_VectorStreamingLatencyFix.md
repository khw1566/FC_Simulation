# 이동 시 건물·도로 표시 지연 수정

- 기존에는 시작점 반경 3km만 준비한 뒤 게임에 진입했다. 변경 후에는 설정된 가시거리와 바깥 1.5km를 초기 준비 대상으로 사용한다. 건물 상주 한도 8만 동은 유지된다.
- 기존 대기열은 이동 후에도 이전 위치를 기준으로 모두 처리했다. 이제 250m 이상 이동하면 현재 처리 중인 작은 묶음을 마친 뒤 현재 위치 기준으로 다시 정렬한다.
- 건물 묶음마다, 도로 하나마다 무조건 한 프레임을 기다리던 처리를 누적 4ms 작업 예산으로 변경했다. 개별 메시 생성 자체가 4ms를 넘는 경우까지 선점하는 방식은 아니다.
- 건물 상주 한도 도달 시 전체 대기열을 종료하여 뒤에 남은 도로가 지연되는 흐름을 수정했다.
- 주변 갱신 간격을 0.5초에서 0.1초로 줄였다. 위치 변경으로 재정렬이 필요한 경우 다음 프레임에 갱신한다.
- 초기 준비 범위가 넓어져 지도 진입 전 대기시간은 늘 수 있다. 전체 80km를 동시에 표시하는 방식은 아니다.
- 실행 테스트와 표시 시간 측정은 수행하지 않았다.
