# 두 캠퍼스 영상 기반 창작 모델 초안

울산대학교와 울산과학대학교 서부캠퍼스를 영상 배치에 맞춰 보강했다. 실측 재현보다 자연스러운 외관을 우선하는 방식으로 변경했으며 현재 결과는 1차 초안이다.

- 기존 API 키를 이용해 브이월드 Satellite WMTS 영상 타일 49개를 수집했다. 확대 수준 17의 지상 픽셀 간격은 약 0.97m이며 2048×2048 정합 영상으로 만들었다. 0.1m 실측 영상이 아니다. 촬영 시점은 확인되지 않았다.
- 영상 작업 구역은 지도 좌표 X -850~650m, Z -850~850m이다. 위경도 선형 지도 축에 맞춰 메르카토르 타일을 재표본화했다.
- 이름과 주소에서 추출한 기존 후보 75개에 서부캠퍼스 영상 판독 작업 구역 안의 건물 31개를 더해 106개 건물 후보를 보강했다. 캠퍼스 소속 및 최신 철거 상태는 확정하지 않았다.
- 기존 윤곽과 양수 높이를 유지하면서 창문, 옥상 난간, 내부에 들어가는 옥상 설비, 캐노피 및 근사 계단을 생성한다. 주요 부지 메시에는 충돌체를 추가했다. 계단과 캐노피는 외관용이며 개별 충돌체는 없다.
- 건물 주변 3m 확장 윤곽을 포장부지로 만들고 윤곽의 지형 표본 최대 높이에 맞춘다. 주변 지형까지 내려가는 측벽은 옹벽처럼 표현한다. 이는 창작 기초부지이며 측량된 대지 경계가 아니다.
- 기존 COP30 기반 높이맵은 유지한다. 영상 패치는 지형 표면을 따라가며 운동장, 도로, 주차장 및 조경은 현재 주로 영상으로 보인다. 나무와 운동 시설을 모두 입체화한 결과는 아니다.
- 일반 지도 실행의 BuildingRoadManager에도 영상 표면과 건물 보강을 연결했다. 미리보기는 독립 장면이며 지도 전체의 도로·주변 건물·비행 제어를 포함하지 않는다.

## 실행과 조정

`previews/preview_ulsan_campus.bat`를 실행한다. 마우스 드래그로 회전하고 휠로 확대한다. 1은 전체, 2는 서부캠퍼스, 3은 울산대학교를 보여준다.

`campus_building_policy.gd`의 영상 작업 구역을 수정해 대상 후보를 조정할 수 있다. `campus_architecture_builder.gd`에는 창문 간격, 난간과 계단 형태가 분리되어 있다. `campus_art_model.json`은 생성 방식의 기록이며 실행 시 읽는 편집 설정은 아니다.

영상 재수집은 `.venv_campus/Scripts/python.exe pipeline/collectors/campus_imagery_collector.py`로 수행하며 Pillow가 필요하다. 현재 환경에서는 설치된 Python312 라이브러리 경로를 PYTHONPATH로 지정했다. 지정된 기존 khw 계정 Python 경로가 없어 프로젝트 가상환경을 사용했다.

## 검증 및 한계

- Godot 4.3 Compatibility 렌더러에서 실제 장면 실행과 PNG 캡처를 확인했다. 렌더 로그에서 건물 후보 106개를 확인했다.
- 오목한 건물 윤곽에 옥상 설비가 바깥으로 놓이지 않는지, 포장부지 좌표가 유효한지, 충돌체와 창문이 생성되는지 검증했다.
- 영상·영상 메타데이터·창작 모델 기록을 지도와 generated 매니페스트에 SHA-256, 경계, 고도 범위 및 해상도와 함께 색인했다. 새 모듈도 두 module_index에 등록했다.
- PNG를 파일로 직접 읽는 현재 프로젝트 방식은 에디터에서 동작하지만 Godot 내보내기에는 원본 PNG 포함 설정이 추가로 필요하다. 배포 빌드를 검증한 것은 아니다.
- 기존 지형 해상도가 건물 주변의 세밀한 토목 형상을 제공하지 않는다. 높은 기초부지 일부와 영상에 남아 있는 건물 그림자는 근접 장면에서 추가 수작업 보정 대상이다.

영상 API 형식은 [브이월드 공식 활용 예제](https://github.com/V-world/Utilization-Model/tree/master/utilization-model)를 참고했다. [울산대학교 공식 캠퍼스맵](https://www.ulsan.ac.kr/kor/CMS/CampusMgr/list.do?mCode=MN057)은 건물 배치 확인 참고자료다. 영상 출처는 국토교통부 브이월드다.
