# 울산광역시 철도 및 주기 운행 열차 구현

울산광역시 80km 맵을 선택하면 기존 지형 준비 후 철도 및 열차 시스템이 자동 구성된다. 전체 맵 실행은 수행하지 않았으며 별도 선로·열차 모델과 실제 벡터 자료로 경량 검증했다.

## 구현 범위

- OpenStreetMap 원본 선형 1,525개에서 동해선 425개, 경부고속선 352개를 분리했다. 측선과 다른 노선은 제외했다.
- 동해선 운행 경로는 약 46.35km, 경부고속선은 약 89.31km이며 지도 범위 내 연결망을 사용한다. 양방향은 서로 다른 실제 선로 경로를 사용한다.
- 동해선은 기장·일광·좌천·월내·서생·남창·망양·덕하·개운포·태화강 10개 역, KTX는 울산·경주 2개 역의 OSM 역 또는 정차 노드에 연결했다.
- 동해선은 자갈 도상, 콘크리트 침목, 4량 전동차, 청색·적색 띠, 다중 출입문으로 구성했다.
- KTX는 콘크리트 도상, 20량 편성, 길이가 다른 동력차, 경사진 선두부, 청색 띠와 동력차 측면 환기구로 구성했다.
- 궤간 1.435m 레일, 전차선과 지주를 생성하며, 교량·터널 속성을 지형 표고 샘플링에 반영했다.
- 열차는 가속·등속·감속·역 정차를 수행하며 각 객차가 선로 곡선과 경사를 따로 따라간다. 출발 주기에 따라 양방향 여러 편이 동시에 운행한다.

## 기본 운행 설정

| 항목 | 동해선 | KTX |
|---|---|---|
| 방향별 출발 간격 | 120초 | 180초 |
| 반대 방향 첫 출발 지연 | 60초 | 90초 |
| 최고 속도 | 30m/s, 108km/h | 83.33m/s, 약 300km/h |
| 가속·감속 | 0.8m/s² | 0.5m/s² |
| 중간역 정차 시간 | 25초 | 40초 |
| 편성 | 4량 | 20량 |

시간은 게임 실행 후 누적 시뮬레이션 초이며 주야간 시계와 독립적이다. 공식 열차 시간표와 연결된 실시간 운행은 아니다. 실제 시각표를 재현하려면 별도 시간표 입력 및 출발 시각 연동이 필요하다.

## 설정 및 자산 갱신

`config/ulsan_railway_services.json`에서 주기, 속도, 정차 시간, 차량 색상 및 편성을 수정하고 프로젝트 루트에서 아래 명령을 실행한다.

```powershell
./pipeline/run_railways.ps1
```

원본 지도 데이터까지 재수집하려면 `./pipeline/run_railways.ps1 -Collect`를 실행한다. 네트워크 연결이 필요하다. 역 수집은 OSM 원본 API의 소규모 영역을 사용한다.

결과는 `godot_project/assets/generated/railway/network.json` 및 `services.json`에 저장되며 기존 생성 자산 매니페스트에 SHA-256, 바운딩 박스와 해상도 정보를 기록한다. 벡터 자체의 고도는 정의하지 않고 실행 시 지형 표고를 샘플링하므로 매니페스트의 고도 최솟값·최댓값은 null로 표시하고 설명을 함께 기록했다.

## 성능 및 모듈 구조

- 렌더링 선로를 약 500m 단위로 분할하고 침목·지주에는 MultiMesh를 사용한다.
- 가까운 열차만 모델을 생성하며 멀어진 모델은 숨겨 재사용한다. 열차 메시 및 재질은 PackedScene 캐시로 공유한다.
- 경로 보간, 운행 단계, 열차 모델, 반복 배차, 선로 모델과 월드 구성을 각각 독립 모듈로 분리했다.
- 두 모듈 인덱스를 갱신했다. 기존 건물·도로 관리자에는 철도 로딩 연결만 추가했다.

## 검증 결과 및 한계

- 경량 회귀 검사 5,316개 통과, 실패 0개. 실제 경로의 모든 간선이 원본 렌더링 선로에 존재하는지와 양방향 분리, 정차, 속도 제한, 주기 배차, 편성 및 모델 수 상한을 확인했다.
- NVIDIA OpenGL Compatibility 렌더러에서 별도 경량 모델을 렌더링하고 종료 시 오류가 없음을 확인했다.
- 검증 자료: `261004_RailwayValidation.json`, `261004_railway_validation.log`, `261004_railway_donghae.png`, `261004_railway_ktx.png`.
- 차량 외형은 절차적으로 만든 단순화 모델이다. 정밀 실차 CAD 형상, 실내, 승객, 소리, 신호와 분기기 제어, 승강장 모델은 포함하지 않는다.
- 경로 끝에서 편성 생성·회수 방식으로 반복 운행한다. 실제 회차 및 차량기지 운용은 구현하지 않았다.
- 교량·터널 표고는 DEM과 원본 구조물 태그를 이용한 근사치다. 설계 종단면에 기반한 철도 구배나 터널 내부 단면은 재현하지 않았다.
- 전체 울산 맵의 실제 지형과 겹치는 구간, 도로·건물 간섭 및 총 프레임 성능은 검증하지 않았다.
