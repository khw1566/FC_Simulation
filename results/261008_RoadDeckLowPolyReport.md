# 교차로·보행 데크 경량화 보고
최근 추가한 109종을 같은 파일명으로 단순화했다. 게임에는 적용하지 않았다. 기존 도로·보행로 239종은 유지했다.

## 변경 결과

| 항목 | 변경 전 | 변경 후 | 감소율 |
|---|---:|---:|---:|
| 109종 합계 삼각형 | 38,142 | 8,326 | 78.2% |
| 109종 GLB 파일 크기 | 2,920,044바이트 | 727,788바이트 | 75.1% |
| 폭 3m 종방향 목재 직선 데크 | 312 | 64 | 79.5% |
| 폭 3m 목재 90도 데크 | 1,086 | 162 | 85.1% |
| 폭 3m 경사 데크 | 612 | 36 | 94.1% |
| 케이블 90도 난간 | 2,088 | 156 | 92.5% |
| 8차선 블록 진입부 | 1,812 | 14 | 99.2% |

삼각형 수는 모델별 메시 합계다. 씬 파일과 모델 파일을 중복해서 세지 않았다. 프리뷰 이미지는 GLB 파일 크기 합계에 포함하지 않았다.

## 단순화 내용

- 개별 블록과 목재 판재를 제거했다. 표면은 단색과 적은 수의 큰 구획선으로 표현한다.
- 미세 색상 변화와 반복 타일을 제거했다. 외부 이미지 텍스처는 사용하지 않는다.
- 곡선은 45도 3구간, 90도 5구간으로 줄였다. 내부 곡면은 각진 형태로 표현한다.
- 난간의 촘촘한 세로 살과 원통 케이블을 제거했다. 기둥과 두 가로대로 단순화했다.
- 프레임의 가로 보 수를 줄였다. 지지대의 기초와 대각 보강을 제거했다.
- 횡단보도 줄무늬 수를 줄였다. 진입부와 노면 표시는 계속 독립적으로 교체할 수 있다.

## 유지한 규격

- 파일명, 에셋 종류 수, 접속점 이름을 유지했다.
- 접속 위치·바깥 방향·폭·표면 높이는 변경 전후 일치했다. 숫자 비교 허용 오차는 1e-8이다.
- 기존 보행로와 데크의 기본 접속 높이는 0.15m다. 경사로 끝 높이와 광장 개구 폭도 유지했다.
- 난간 부착 기준과 지지대 상단 기준은 유지했다.
- 기존 도로·보행로와 게임 파일의 보호 목록은 모두 작업 전후 해시가 같았다.

## 산출물과 확인

- 변경 에셋과 갱신 프리뷰: `godot_project/assets/generated/road_assets/`
- 생성 규칙: `pipeline/processors/road_assets/low_detail.py`, `decks.py`, `junctions.py`
- 경량 재질·품질 메타데이터: `detail_profile=low_poly_flat_v1`, `external_textures=false`
- 기존 확장 생성기로 109종을 다시 생성했다. 모듈 인덱스와 전용·공통 매니페스트를 갱신했다.
- 매니페스트 해시 불일치는 0개다. 전체 맵과 원본 프로젝트 임포터는 실행하지 않았다.
- 프리뷰는 생성 메시의 경량 투영 이미지다. 이번 변경에서는 Godot 실행 검사를 추가하지 않았다.
