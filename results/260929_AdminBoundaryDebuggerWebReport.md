# 행정구역 시각화·디버깅 웹 도구

## 구현 내용

- `tools/admin_boundary_debugger/`에 별도 로컬 웹 도구를 구성했습니다.
- 울산 60km 맵의 Godot 월드 X/Z 좌표계로 `real_districts.json`의 행정경계를 그립니다.
- 행정 레벨 4/6/8/10을 따로 표시하거나 숨길 수 있습니다.
- 지도 클릭 또는 X/Z 입력으로 좌표를 검사하고, 해당 위치에 포함되는 행정단위와 최하위 행정경계를 확인할 수 있습니다.
- 이름/경계 코드 검색, 경계 상세정보, 검사 결과 JSON 저장을 제공합니다.
- 별도 정적 웹 서버 실행 파일, 사용 안내, 프로젝트 `module_index.json` 등록을 추가했습니다.

## 실행

`tools/admin_boundary_debugger/run_debugger.bat`을 실행하면 로컬 서버를 열고 기본 브라우저에서 디버거를 표시합니다. 서버 실행에는 지정된 Python 3.12 경로를 사용합니다.

## 데이터 및 좌표 기준

기본 데이터는 `godot_project/assets/maps/ulsan_metro_60km/real_districts.json`이며, 자동 연결이 되지 않을 때는 웹 화면에서 파일을 직접 불러올 수 있습니다. 월드 중심은 X/Z=(0,0), 북쪽은 Z 음수, 남쪽은 Z 양수입니다.

## 확인 범위

파일과 인덱스 구성을 점검했습니다. 브라우저에서의 실행 검증은 수행하지 않았습니다.
