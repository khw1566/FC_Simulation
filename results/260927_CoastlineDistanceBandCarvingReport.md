# 260927 해안선 거리밴드 기반 지형 보정 보고서
작성일자: 2026-09-27
작성자: Antigravity AI

## 1. 문제 진단
- 수계마스크(watermask)가 8비트 PNG 이진값(0 또는 255)으로 저장되어 있어, 정규화 시 0.0 또는 1.0만 존재
- 기존 코드는 wm_val 0.15~0.40 구간의 그래디언트 전환을 가정했으나, 해당 구간이 실제로 존재하지 않음
- 결과적으로 해안선 경계부의 호안 절벽 형성, 해저 침강, 육지 최소 고도 보장 로직이 모두 미작동

## 2. 수정 내용

### 알고리즘 전면 교체: BFS 기반 거리밴드 방식
- 수계마스크의 이진(0/1) 특성을 수용하여, 해안선 경계 픽셀을 BFS로 탐색
- 해안선 경계에서 양방향(수역/육지)으로 6픽셀 반경의 거리 맵 생성
- 거리 맵을 기반으로 아래 3단계 고도 보정 적용:

| 영역 | 거리 | 보정 동작 |
|------|------|-----------|
| 수역 심부 | d >= 6 | 해저 -5.0m로 확실한 침강 |
| 수역 경계밴드 | 0 < d < 6 | 해수면→해저 선형 보간 |
| 수역 경계 직상 | d == 0 | 해수면 -1.0m 바로 아래 |
| 육지 호안부 | d <= 2 | 최소 +1.5m 호안 절벽 확보 |
| 육지 근방 | 2 < d <= 6 | 최소 +0.5m 침강 방지 |

### 기존 대비 개선점
- 해저 침강 깊이: -2.5m → -5.0m (더 확실한 해수면/육지 구분)
- 육지 최소 고도: +0.8m → +1.5m (호안 절벽 명확화)
- 경계 전환: 임계값 기반 이산적 분기 → 거리 기반 연속 그래디언트
