# 혼합 조립용 도로·보행로 에셋 제작 보고
독립 GLB 모델 239종과 대응 Godot 씬을 제작했다. 혼합 조립 예제 씬 1개를 추가했다. 게임과 지도에는 적용하지 않았다.

## 제작 결과

| 종류 | 모델 수 | 내용 |
|---|---:|---|
| 차도 | 79 | 총 1~8차선, 7개 용도, 직선·45도·90도 곡선, 2·4차선 교차로 |
| 보행로 | 108 | 24개 표면 유형, 폭 1.5·3·4.5m 직선, 폭 3m 곡선과 6개 표면의 분기 |
| 차선 표시 세트 | 24 | 1~8차선별 직선·곡선 표시. 차도에서 분리 가능 |
| 전환부 | 7 | 차선 수 전환 4종, 보행 폭 전환 2종, 보도 턱 낮춤 1종 |
| 부속물 | 11 | 경계석·배수·난간·방호울타리·볼라드·녹지·점자블록·계단 |
| 개별 노면 표시 | 10 | 실선·점선·이중선·횡단보도·정지선·화살표·자전거 표시 |

GLB와 대응 씬은 같은 에셋이다. 파일 개수를 종류 수로 중복 계산하지 않았다. 전환부와 부속물도 독립 조립 모델로 포함했다.

## 혼합 사용 규격

- 직선 길이는 12m다. Y축은 높이다. 1단위는 1m다.
- 차도 표면은 0m, 보행로 표면은 0.15m다. 차선 폭은 3.25m다.
- 연결점의 위치, 바깥 방향, 단면 종류, 폭, 표면 높이를 기록했다. 차도는 총 차선 수도 기록했다.
- 같은 폭과 높이의 서로 다른 보행로 소재는 연속 연결할 수 있다. 폭 또는 높이가 다르면 전환부를 사용한다.
- 차도 GLB에는 차선 표시가 없다. 차도 씬에서 독립 표시 인스턴스를 제공한다. 교체 또는 제거할 수 있다. 비포장 차도에는 기본 표시가 없다.
- 경계석·녹지·난간·점자블록은 표면과 독립적으로 조합할 수 있다. 점유 범위를 고려해야 한다.
- `road_walk_mix_demo.tscn`은 여러 보행로 소재와 부속물의 혼합 예제다. 실행 씬에 연결하지 않았다.
- 기존 산업 시설·역사·보행교·철도 에셋은 별도 조립 씬에서 참조할 수 있다. 원본 계열의 기준점과 footprint를 확인해야 한다.

## 확인 결과

- 대표 에셋 씬 9개와 혼합 조립 예제 1개를 Godot 4.3의 독립 프로젝트에서 읽고 인스턴스를 생성했다. 10개 모두 통과했다.
- 확인용 원본 읽기는 안정된 파일만 사용했다. 복사·임포트·캐시는 `previews/asset_browser/road_assets_check/`에 한정했다.
- 전체 맵, 원본 프로젝트 임포터, 원본 에디터는 실행하지 않았다. 에셋 브라우저 실행파일은 재빌드하지 않았다.
- 전용 매니페스트 485개 항목의 파일 존재와 SHA256을 확인했다. 누락과 해시 불일치는 0개다.
- 작업 전 기록한 게임 설정·씬·도로 코드 25개는 작업 후 해시가 같았다.
- 신규 소스 모듈의 최대 길이는 166라인이다. 패키지 `__init__.py`와 두 모듈 인덱스에 노출했다.
- 충돌체, 지형 밀착, 자동 지도 배치와 경로 탐색은 포함하지 않았다. 프리뷰 이미지는 Godot 조명 렌더가 아닌 경량 투영 이미지다.
