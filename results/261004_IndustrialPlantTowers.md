# 플랜트 탑과 연기 시각화
산업 스카이라인을 구성하는 범용 탑 6종과 연결 랙 6종, 연기·증기 3종 및 조립 예제를 만들었다. 독립 출력 경로는 `godot_project/assets/generated/industrial_plant`다. 기존 공단 에셋과 게임 월드를 다시 생성하거나 수정하지 않았다.

- 탑: 90m 표식 연통, 55m 강철 연통, 62m 3구 연통, 72m 격자 플레어, 다단 공정 탑, 세정·배기 탑.
- 연결: 3열 직선·곡관·분기·공유 교차 헤더·5→9m 높이 전환·2층 랙. 기존 반경 0.32m/열 간격 1.1m 규격을 사용한다.
- 연결 도우미: 동일 규격·균일 축척의 포트를 반대 방향으로 맞추고 모듈 전체를 이동·회전한다.
- 효과: 최대 96 GPU 입자, 연기량·풍향·흐름 강도·상승 조절, 인스턴스별 공정 재질. 실제 기상 확산 계산과 자동 거리 LOD는 포함하지 않았다.
- 실제 정유 공정 탑과 플레어는 기본 연기를 끈 상태다. 불꽃은 구현하지 않았다.
- 출력 구조: 모델 GLB, 효과를 포함한 Godot 씬, 연결·배출구 메타데이터 카탈로그, 전용·공통 매니페스트, 메시 미리보기, README.

## 경량 확인 결과
- 생성 GLB 컨테이너와 메시 좌표·법선의 유한성을 확인했다.
- Godot 4.3 전용 복사본에서 모델·효과 15개 씬의 로드, 연결 포트 위치·반대 방향 정렬, GPU 연기 렌더를 확인했다.
- 원본 Godot 임포터와 전체 지도는 실행하지 않았다. 전용 복사본의 LOD 생성에서 `Ignoring face with non-finite normal in LOD generation` 경고 1건이 있었으며 씬 로드·연결·렌더 오류는 없었다. 장거리 LOD 품질은 확인하지 않았다.
- 캡처: `previews/industrial_plant_check/capture.png`. 검사 캐시·로그는 같은 전용 경로에만 기록한다.
- 최종 색인은 `pipeline/indexer/build_asset_index.py`로 수동 갱신한다. 전체 파일 수와 보류 목록은 중앙 인덱스에 기록한다.
