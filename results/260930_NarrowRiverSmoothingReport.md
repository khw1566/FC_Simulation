# 좁은 하천 경계 개선 및 Godot 오류 확인

- 원인: 수계 래스터는 정수 픽셀로 생성되며, 기존 지형 셰이더는 0.5 임계값에서 물/육지를 분리했다. 이 때문에 선형 필터가 있어도 좁은 대각선 수계가 구슬 또는 계단 모양으로 보였다.
- 수정: 렌더링 마스크에 네 번의 선형 샘플을 사용하는 B-spline 보간을 적용했다. 수면 색상·노멀·반사율을 같은 연속 가중치로 전환하고, 원거리에서는 밉맵의 면적 평균을 사용한다. 좁은 물줄기 중심의 색상을 유지하도록 전환 구간을 조정했다.
- 원본 수계·높이맵과 물리 판정은 유지했다. 렌더링 복사본에만 밉맵을 추가한다. 새 수계나 실측 좌표를 생성한 작업은 아니다.
- 검사: 실제 OpenGL 렌더러의 셰이더 컴파일 및 실행 성공, 지형 관리자 구문 검사 성공. 1픽셀 테스트 곡선과 실제 울산 80km 수계 마스크의 좁은 하천 구역을 동일한 조건으로 전후 렌더링했다. 실제 수계 비교 이미지에서 단절된 픽셀 경계가 연속 경계로 완화됨을 확인했다. 전체 도시 지도에서 수동 비행은 수행하지 않았다.
- 비교 이미지: `river_filter_actual_before.png`, `river_filter_actual_after.png`. 검증 로그: `river_filter_validation.log`.
- Windows 응용 프로그램 기록에서 2026-09-30 16:27:26 Godot 4.3 예외 코드 0xc0000005, 오류 오프셋 0x435131d를 확인했다. 앞선 커스텀 모델 검사 때 작업용 Godot 실행도 시작 중 충돌한 적이 있다. 첨부 창만으로 해당 실행과 동일한 사건 또는 내부 결함 원인을 확정할 수 없다.
- 이후 실행한 직접 호출 방식의 OpenGL 검사들은 정상 종료했다. 이 사실은 엔진의 모든 메모리 접근 오류가 해결됐음을 의미하지 않는다. 이번 하천 변경 검증 중에는 동일 충돌이 재현되지 않았다.
