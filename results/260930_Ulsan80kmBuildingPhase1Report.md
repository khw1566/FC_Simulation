# 울산 80km 건물 구축 1일차 진행 보고서

## 대상과 사전 검증

- 대상은 80km 맵의 기존 60km 건물 자산 경계 밖 동부·북부 외곽이다.
- VWorld 요청 후보 218셀을 생성했다. 셀의 지리 면적을 계산해 최대값 5.557km²를 확인했다. 모든 후보 셀이 10km² 미만이다.
- 80km 맵 설정 경계 안에서 60km 자료와 중첩되는 외곽 셀은 재수집하지 않도록 구성했다. 피처도 응답 셀 경계 내 도형 좌표를 확인해 필터하도록 했다.
- 80km 맵은 현재 `buildings_roads`를 60km JSON에 연결한다. 따라서 신규 외곽 자료는 이후 60km 기준 월드 좌표계로 변환해 해당 JSON에 병합해야 80km 렌더러에서 유지될 수 있다.

## 실행 결과

- 2026-09-30 최초 후보 셀의 첫 페이지를 요청했으나, 실행 환경의 네트워크 정책이 VWorld HTTPS 연결을 차단해 실패했다(Windows 오류 10013).
- 실패 페이지 재시도를 포함해 요청 2회를 진행 매니페스트에 기록했다. 추가 재시도는 수행하지 않았다.
- 완료 셀 0/218, 수집 피처 0, 신규 고유 건물관리번호 0이다. 런타임 JSON과 자산 매니페스트는 건물 변경이 없어 수정하지 않았다.
- 실패 셀 `phase1_80km_outer_north_y00_x00`, 페이지 1은 미완료 상태로 남겼다.

## 재개 방법과 제한

- 네트워크 접근이 허용되는 실행 환경에서 Python 3.11 `requests` 설치본으로 `pipeline/collectors/ulsan_80km_building_collector.py`를 실행하면 미완료 셀부터 다시 시작한다. 코드 문법 검사는 통과했다.
- 수집기는 하루 600회 목표, 절대 상한 700회로 제한하고 각 요청 전 매니페스트에 호출을 기록한다.
- 계정의 실시간 쿼터 잔여량은 로컬에서 확인하지 못했으므로, 다음 재개 전에 VWorld 계정 한도를 확인해야 한다.
- 네트워크 차단이 해소되기 전에는 1일차 건물 수집 및 런타임 반영이 완료되지 않은 상태다.
