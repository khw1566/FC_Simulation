# 50km 고고도 광역 원경 개선
작성일: 2026-10-04. 현재 코드·생성 자산·독립 렌더 결과를 기준으로 작성했다.

## 변경
- 자료 밖 경계 표고 외삽을 제거하고 한국·일본·주변 해역을 포함하는 실제 광역 고도 자료를 추가했다.
- 지도 외곽 확장: 140km → 900km. 울산 80km 기준 사각 외곽 한 변 1,880km.
- 광역 원본: 공개 Terrarium zoom 8 타일 361개. 캐시 재사용과 동시 요청 4개, 실패 시 제한된 재시도.
- 광역 아틀라스: 4096 × 4096 float32. 자료 bbox {'west': 116.71875, 'east': 143.4375, 'north': 45.089035564831015, 'south': 23.241346102386135}.
- 근거리 경계 아틀라스: 129 → 513. 실제 게임에서는 로드가 끝난 상세 지형의 경계를 읽어 연결한다.
- 원경 메쉬: 16,384 → 524,288개 삼각형, 263,168개 정점. 지형 경사를 반영한 면적 가중 법선.
- 높이 연결 6km, 곡률 연결 12km, 지표 피복 색상 연결 18km.
- 기존 지형의 숲·농지·도시·암석·모래 팔레트와 피복 텍스처를 연결한다. 상세 지형의 심플 표시 모드를 실시간으로 따라간다.
- 원경은 상세 범위를 비우고 지구 곡률을 적용한다. 기존 평면 해수면은 상세 지도 안에 한정하여 원경 위로 덮이는 문제를 막았다.
- 근거리·원경 수면 모두 고도/거리에 따라 물결과 강한 정반사를 억제하여 색상 연결과 원거리 깜박임을 개선했다.
- 카메라 far는 고도별 지평선 거리에 따라 450km~1,600km 범위에서 조절한다. 50km 기준 약 1,280km.
- 표본·메쉬 배열 계산은 별도 작업 스레드에서 수행하며 원경의 충돌·건물·도로·그림자는 생성하지 않는다.

## 독립 확인
전체 게임·지도 로딩을 실행하지 않았다. 프리뷰 전용 소형 프로젝트에서 원경, 축소 중앙 표본, 기존 대기 셰이더와 50km 카메라만 사용했다. 원본 프로젝트의 임포터나 .godot는 실행하지 않았다.

- 실패 항목: 0개.
- 쓰시마·큐슈·혼슈 육지 표본과 대한해협 음수 표고를 확인했다.
- 경사진 법선: 176,123개.
- 작업 스레드 계산: 1457ms. 그동안 주 스레드가 90프레임 진행했다. 전체 게임 FPS 측정은 아니다.
- 화면: `results/261004_HighAltitude50km.png`.

## 정밀도와 범위
4096 표본은 울산 주변에서 약 600m 간격이다. 원본 출처가 섞인 광역 원경 자료이며 개별 타일의 측량 정밀도나 최신성을 조사했다고 주장하지 않는다. 50km에서 해안선·섬·산지 음영을 보여주는 용도이며 외곽의 건물·도로 또는 실제 지표 피복을 추가한 것은 아니다.

곡률은 기존 평면 지도와 연결하는 시각 근사다. 상세 지도와 플레이어의 비행 좌표계를 구면으로 변경하지 않았다. 기존 상세 지형은 평면으로 남으며 전체 게임 성능·모든 날씨·주야간 조합은 이번 경량 확인 범위 밖이다.
