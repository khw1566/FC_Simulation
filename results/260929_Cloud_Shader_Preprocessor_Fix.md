# 구름 셰이더 전처리 오류 수정

- 전달받은 로그는 `#include`가 전처리되지 않은 채 셰이더 토크나이저로 들어가 실패했음을 보여준다. 화면의 큰 박스는 구름 볼륨을 담는 메시이며, 밀도·투명도 셰이더가 적용되지 않은 상태다.
- 밀도 함수를 메인 셰이더에 통합하고 `#include` 의존성을 제거했다. 파일은 800라인 제한 이내다.
- 이어서 같은 문제가 발생할 수 있는 `#if`도 제거했다. 실제 렌더링 방식에 따라 생성기가 `compatibility_depth` 값을 전달한다. Compatibility는 깊이를 -1~1로 변환하고 Forward+/Mobile은 0~1을 사용한다.
- 사용하지 않는 밀도 include 파일을 제거하고 모듈 인덱스를 갱신했다.
- 구름 종류·품질 상한·전환 시간은 유지했다.
- 게임 실행 및 GPU 셰이더 컴파일 재확인은 수행하지 않았다. 수정된 자산은 게임을 종료한 뒤 다시 실행해야 반영된다.
