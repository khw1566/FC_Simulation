# 열차 경사 배치 수정

객차 중심 한 점의 선로 방향 대신 앞뒤 대차(객차 길이의 ±0.32)의 선로 위치를 사용한다. 차체 중심은 두 접점의 중점, 차체 방향은 접점 간 벡터로 계산하여 높이와 기울기를 함께 따른다. 역방향은 앞뒤 접점 순서를 바꿔 경사를 보존한다.

- 변경: `godot_project/scripts/terrain/railway_train_service.gd`의 `_pose`.
- 경량 검사: 4량 편성, 10% 경사에서 양방향 피치 및 접지 높이, 경사-평탄 경계 기울기의 연속성 통과.
- 검사 스크립트: `previews/railway_grade_check/verify.gd`.
- 전체 지도와 실제 운행 화면은 실행하지 않았다. 차체는 직선 강체이며 급곡선이나 실제 선형 자체의 불연속을 변경하지 않는다.
- 모델·조명·객차 수·시간표는 유지한다. 생성 에셋 파일 변경이 없어 에셋 재생성 및 프리뷰 실행파일 재빌드는 수행하지 않았다.
