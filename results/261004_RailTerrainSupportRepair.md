# 철도 주변 지형과 교량 지지부 수정

- 일반 철도 절토 영역의 지형 fragment discard를 제거했다. 낮은 LOD 지형이 종단 높이보다 높다는 이유로 지표를 비워 검은 구멍을 만들던 처리를 중단한다. 터널 내부의 높이 제한 개구부는 유지한다.
- 일반 철도 절토 마스크에 걸친 충돌 삼각형을 통째로 제거하는 처리를 중단한다.
- 철도 성토 측면의 12m 하향 매립 면을 제거하고 측면 법선을 위쪽으로 정리했다. 보조 성토 메시의 그림자는 비활성화하여 삼각형 그림자 흔적을 방지한다.
- 범용 교각은 고정 8m 대신 각 교각의 실제 지표 높이를 조회해 길이를 계산한다. 교각은 수직으로 유지하고 기초는 지표 아래 1m까지 연결한다.
- 교량 에셋은 모든 음수 높이 부재를 일괄 변형하던 방식 대신 structure의 -2.7m 아래 지지부만 실제 지표까지 이어지도록 변형한다. 실제 원본 메시의 최저점을 사용하고 상판·거더·아치는 보존한다. 변형 후 법선을 다시 생성한다.
- Godot 문법 검사 통과. 실제 OpenGL 렌더러의 독립 32m 교량 검사에서 일반 교각과 에셋 교각의 지표 연결, 상판 높이 유지 확인: checked_supports=2, failures=[].
- 헤드리스 더미 렌더러는 MultiMesh 변환 조회를 지원하지 않아 해당 확인에는 숨김 경량 창을 사용했다. 전체 맵 실행 및 첨부 위치의 화면 재현은 수행하지 않았다.
- 변경 지형 셰이더를 포함한 에셋 색인 갱신 완료: 23,168개 파일, pending 0개. 모델 원본과 프리뷰 실행파일은 변경하지 않았다.
