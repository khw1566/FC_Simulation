# 범용 공단 에셋 제작
실제 시설 위치나 비공개 데이터를 사용하지 않고 공단의 무작위 절차 배치에 사용할 독립 외관 모델을 제작했다.

- 공장 3종: 박공지붕, 톱니지붕, 평지붕 공장.
- 설비 4종: 증류탑, 대형 연통, 원통형 액체저장고, 구형 LPG저장고.
- 배관 3종: 직선, 90도 곡관, 분기형. 접속면 중심 위치와 바깥 방향을 제공했다.
- 10종 모두 GLB와 Godot PackedScene으로 저장했고 바닥 원점 Y=0과 미터 단위를 통일했다.
- 점유 범위, 로컬 AABB, 권장 무작위 축척 0.85~1.15 및 기본 배치 간격 3m를 카탈로그에 기록했다.
- 저장 경로는 `godot_project/assets/generated/industrial/`이다.
- 전용 및 공용 매니페스트에 해시·bbox·고도·해상도를 기록하고 두 모듈 인덱스를 갱신했다. 공용 JSON은 최신 내용을 읽어 해당 항목만 병합하며 동시 변경 여부를 확인한다.
- 생성 중 GLB 컨테이너 헤더와 길이를 확인했다. 생성 메시를 깊이 버퍼로 투영한 미리보기에서 외관을 확인했다.
- 개발 속도 지침에 따라 추가 회귀 테스트, Godot 실행 및 기존 맵 로딩은 수행하지 않았다. 실제 엔진에서의 가져오기·배치 결과는 이번 작업의 확인 범위에 포함되지 않는다.
- 에셋 프리뷰 실행파일과 원본 `.godot`, `.import`는 수정하지 않았다. 독립 프리뷰는 기존 자동 감지를 사용한다.
- 공단 영역의 무작위 배치 생성기와 실제 지도 연결은 구현하지 않았다. 이번 결과는 해당 작업에 사용할 에셋 묶음이다.

세부 구성과 재생성 명령은 에셋 폴더의 README.md에 기록했다.
