# 고도별 대기와 맵 밖 원경 구현

- `main_world.tscn`에 독립적인 고도 대기 제어기와 원경 지형 관리자를 연결했다. 기존 낮·밤, 태양·달·별 계산을 유지하고 하늘 색의 광학 산란 항만 추가했다.
- 지표에서는 푸른 하늘이 나타나고, 고도가 높아질수록 공기 밀도와 천정 방향의 광학 경로가 감소해 하늘이 검게 변한다. 8km 규모 높이의 지수 대기, RGB 레일리 소광계수, 태양과 시선 사이 위상함수 및 16회 곡면 광학 경로 적분을 사용하는 실시간 근사다. 수평선 방향은 더 긴 대기 경로로 푸른 띠를 남긴다.
- 기존 날씨 안개는 고고도에서 최소 20%를 유지했지만, 동일한 지수 밀도로 희석하도록 변경했다. 안개의 하늘 영향은 제거해 검은 하늘이 회색으로 덮이지 않도록 했다. 기존 안개 설정의 활성화 여부는 유지한다.
- 원경은 상세 지형 중앙을 비운 별도의 링 메시다. 상세 지형 로딩이 끝난 뒤 경계 표고 512개만 읽어 한 번 생성하며, 경계 32m 안쪽에서 5m 낮춰 겹친 뒤 3km 구간에서 광역 표고로 전이한다. 충돌·건물·도로·그림자는 생성하지 않는다.
- 각 지도에서 경계 밖 140km를 추가하고, 128 구간씩 4변과 방사 방향 16개 링을 사용한다. 지도당 8,704개 정점, 16,384개 삼각형이며 이후 지형 갱신은 없다. 카메라 원거리 클리핑을 최소 450km로 확장하고 고도에 맞춰 근거리 클리핑을 조정했다.
- 기존 DEM 6개를 각각 129×129로 축소한 1,761,620바이트 아틀라스를 생성했다. 울산 80km의 외부는 경상도 140km 자료, 울산과학대 5km의 외부는 울산 80km 자료를 지리 좌표로 재표본화한다. 자료 밖은 경계 표고를 완만하게 낮추는 시각용 외삽으로 처리한다. 실제 신규 지형 측량 데이터나 무한 지형이 아니다.
- 평지 테스트 지도는 원경도 평지를 유지한다. 해수면을 비활성화한 캠퍼스 지도에는 해수면을 강제로 생성하지 않는다.
- 별도 경량 장면에서 대기 밀도·광학 경로, 실제 렌더 픽셀의 고도별 밝기 감소, 지표 푸른색 및 40km 검은 하늘, 6개 지도 원경 표고, 삼각형 상한, 중앙 비움과 충돌 미생성을 검사했다. 104,479건 검사, 실패 0건. 전체 맵 로딩이나 실행은 하지 않았다. 실제 상세 지형과의 경계 조망은 전체 맵 미실행으로 확인하지 않았다.
- 생성 자산의 해시·생성 범위·원본 범위·최소/최대 고도·해상도를 매니페스트에 기록하고 양쪽 모듈 인덱스를 갱신했다.
- 재생성: `.venv_campus/Scripts/python.exe pipeline/processors/build_horizon_terrain.py`. 원경 확장 거리, 아틀라스 해상도와 링 구간 수는 `config/atmosphere_horizon.json`에서 조정한다.
