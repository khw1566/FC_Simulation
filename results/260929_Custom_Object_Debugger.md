# 게임 내 커스텀 오브젝트 디버거

## 사용 방법

- 게임에서 F9 또는 왼쪽 아래의 ‘오브젝트 열람’ 버튼으로 연다.
- 왼쪽 목록에서 교량이나 울산공항을 선택한다. 이름으로 검색할 수 있다.
- 드래그로 회전, 휠로 확대·축소, Shift와 드래그로 화면을 이동한다.
- ‘전체 보기’로 모델 전체가 보이는 구도로 복귀한다. 자동 회전도 지원한다.
- 부재 트리에서 노드를 선택하면 해당 부분으로 카메라 초점을 이동하고 이름, 종류, 미리보기 좌표, 크기를 표시한다. 메시에는 표면 수와 재질 정보, 반복 메시에는 인스턴스 수를 표시한다.
- F9, Esc, 닫기 버튼으로 닫는다. 열기 전의 일시 정지 상태와 마우스 모드를 복원한다.

## 구현

- `custom_asset_catalog.gd`: 자산 폴더 내 독립 3D 씬을 자동 수집한다. 교량 카탈로그의 이름을 표시하고 새 파일은 목록 갱신으로 반영한다.
- `custom_asset_preview.gd`: 독립 SubViewport와 World3D, 중립 조명, 모델 경계 기반 궤도 카메라를 관리한다. 미리보기 인스턴스의 스크립트·처리·충돌을 비활성화한다.
- `custom_asset_debugger.gd`: 목록·검색·부재 트리·정보 패널과 열기/닫기 상태를 관리한다.
- 메인 월드에 등록했으며 F1 도움말에 F9와 F10을 추가했다.
- 열람 중에는 게임을 일시 정지한다. 기존 일시 정지 컨트롤러가 Esc/Alt 및 창 포커스 복귀로 마우스를 가로채지 않도록 연동했다.
- 닫으면 미리보기 모델을 해제하고 별도 뷰포트 렌더링을 중단한다.

## 범위와 확인 상태

- 현재 독립 에셋인 교량 8종과 울산공항을 열람 대상으로 한다. 향후 자산 폴더에 추가한 `.scn`/`.tscn` 파일도 자동 수집한다.
- 미리보기 좌표는 에셋의 로컬 원점 기준이다. 실제 지도 배치 고도나 지형과의 접합 상태를 나타내지 않는다.
- 기존 에셋 파일 자체는 수정하지 않는다.
- 이번 작업에서는 게임 실행이나 자동 테스트를 수행하지 않았다. 실제 화면의 레이아웃과 입력 동작은 실행 확인이 필요하다.
