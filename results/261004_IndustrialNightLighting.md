# 공단 에셋 야간 조명
기존 공단 16종과 플랜트 탑·배관 12종에 시설별 조명 리그를 부착했다. 공장 창문과 출입부, 탑 발판과 표식, 크레인 지브, 저장고 둘레와 배관 작업등에 따뜻한 색·차가운 색을 배분했다.

- 기존 GLB 28개는 이전 중앙 색인의 SHA256과 비교해 모두 변경되지 않았음을 확인했다. 씬의 원본 메시·연결점·연기 노드는 보존하고 NightLighting 자식을 추가했다.
- 실제 광원은 에셋당 1~4개이며 그림자를 끄고 카메라 350~550m 사이에서 소거한다. 장식 메시의 발광과 작은 후광은 별도로 남긴다.
- 각 인스턴스의 재질을 별도로 복제한다. `brightness`, `local_lights_enabled`, `set_night_factor()`로 조절한다.
- 기존 DayNightCycleService 신호를 구독한다. 태양 방향은 CelestialBodyManager가 있으면 읽고, 없으면 시간대에서 계산한다. 태양 광원이 달빛으로 재사용되는 회전은 주야간 판단에 사용하지 않는다.
- 두 공단 생성기에 부착 단계를 연결하여 재생성 시에도 조명을 복구한다. GLB 파일만 직접 사용하는 경우에는 조명이 포함되지 않는다.
- 공유 매니페스트가 일시적으로 잠긴 경우 짧게 재시도한다. 원본 게임 월드, 주야간 서비스와 프리뷰 실행파일을 수정하지 않았다.

## 독립 확인
- Godot 4.3 Compatibility 전용 복사본에서 조명 리그 28개의 로드, 실제 주야간 서비스의 낮 소등·밤 점등, 서로 다른 인스턴스의 광량·재질 독립을 확인했다.
- 야경 렌더는 `previews/industrial_night/night.png`다. 전체 지도와 원본 프로젝트 임포터는 실행하지 않았다.
- 복사본 임포트의 기존 LOD 생성 경고가 있었으며 조명 씬 로드와 야경 렌더 오류는 없었다. 대규모 밀집 배치의 광원 제한·성능은 확인하지 않았다.
- 에셋 인덱스 지침의 공단 야간 조명 분류와 두 모듈 인덱스를 갱신했다. 중앙 색인은 수동 갱신한다.

## 사용 안내
`godot_project/assets/generated/industrial_lighting/README.md`에서 밝기·소등·실제 광원 비활성화·수동 갱신 방법을 확인한다.
