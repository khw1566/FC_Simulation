# 월성 원자력발전소 외관 에셋

월성 1~4호기의 원통형 격납건물과 돔을 참고한 독립 게임용 모델이다. 치수, 건물 간격, 배치는 예술적 근사이며 실측 모델이 아니다. 신월성 1~2호기는 포함하지 않는다.

- Godot에서 `wolsong_npp.tscn`을 인스턴스화한다. 다른 도구에서는 `wolsong_npp.glb`를 사용한다.
- 1 단위는 1 m, Y축은 위쪽이다. 원점은 단지 중심의 지표면이며 기초는 Y=-3 m까지 내려간다.
- 격납건물 4개, 터빈동, 연결동, 보조동, 도로, 울타리를 포함한다. 내부 설비와 물리 충돌체는 포함하지 않는다.
- 외부 텍스처나 런타임 스크립트가 필요 없는 정적 메시다.
- 월드, 지도, 로딩 설정과 공유 매니페스트는 수정하지 않았다. 전용 `manifest.json`에 파일 해시와 로컬 경계, 높이, 삼각형 수를 기록했다.
- 지리 배치가 없는 에셋이므로 `bbox`는 null이다. 실제 맵 배치는 별도로 수행한다.
- 생성기는 기존 `vessels.mesh`의 메시 작성 및 GLB 내보내기 기능을 읽기 전용으로 재사용한다.
- `preview.png`는 생성된 메시를 직접 투영한 참고 이미지이며 Godot 렌더는 아니다.
- 참고: [한국수력원자력 월성 시설 소개](https://cms.khnp.co.kr/eng/contents.do?key=2001).

재생성은 프로젝트 루트에서 실행한다.

```powershell
& .venv_campus/Scripts/python.exe pipeline/processors/wolsong/generate.py
```
