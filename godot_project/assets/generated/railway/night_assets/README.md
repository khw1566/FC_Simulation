# 철로 및 열차 야간 조명

고속철도 KTX와 동해선 열차·철로에 야간 조명을 포함한 독립 Godot 씬이다. 각 계열은 열차, 520m 철로, 조립 예제의 세 가지 씬으로 제공한다. 운행용 생성기에도 같은 조명 모듈을 적용한다.

- 열차: 흰색 전조등, 붉은 후미등, 따뜻한 객실 발광과 거리와 무관한 화면 크기의 식별 표시.
- 철로: 좌우 교대 120m 간격 식별등, 300m 간격 근거리 실제 광원. 철도교·안양교 세트와 터널에도 적용한다.
- 실제 광원: 그림자 비활성화. 철로는 60–110m, 열차 전조등은 180–320m 카메라 거리에서 소거한다.
- 발광 표시: 낮에도 유지한다. 카메라 FOV·해상도에 따라 표시 크기가 달라지며 지형의 깊이 가림을 유지한다. 실제 철도 조명 배치를 재현하는 설정은 아니다.
- 설정: 상위 폴더의 `night_lighting.json`. 열차의 조명 노드는 객차 안에 들어가 객차 수와 운행 배치 로직을 유지한다.

재생성: `.venv_campus/Scripts/python.exe pipeline/processors/build_railway_night_assets.py`

독립 1280×720 Compatibility 야간 렌더에서 KTX·동해선 열차와 철로의 약 1.5km 식별을 확인했다. 전체 맵·안개·운행 중 검증은 수행하지 않았다. 캡처는 `previews/asset_browser/railway_night_capture/images`에 있다.
