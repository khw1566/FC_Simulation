# 교량 에셋 3종
기존 월드 배치와 분리된 정적 Godot PackedScene 에셋이다. 별도 텍스처나 런타임 생성 스크립트 의존성 없이 인스턴스화할 수 있다.

| 씬 | 종류 | 기준 크기 | 삼각형 |
|---|---|---|---|
| gulhwa_daun_crossing.scn | 굴화리–다운동 도보 징검다리 | 보행로 100 × 1 m | 1,824 |
| seonbawi_bridge.scn | 선바위교 | 160 × 24.9 m | 12,960 |
| generic_pedestrian_overpass.scn | 범용 육교 | 중앙 경간 28 × 3 m | 6,132 |

## 배치 및 재사용
- 단위는 m, Y축이 위쪽, Z축이 교량 진행 방향이다. 루트는 교량 중심의 기준 지면 또는 하천 바닥 Y=0에 둔다.
- 징검다리 보행면 높이는 0.65m, 선바위교는 8m, 범용 육교는 6.2m다. 선바위교 높이는 측량값이 아닌 제작 가정이다.
- 징검다리는 좁은 분절 콘크리트 보행판과 하부 받침·수로를 표현했다. 난간 없는 모습은 2023년 기사 기준이며 현재 상태를 보증하지 않는다.
- 선바위교는 직선 보교, 석재 보도, 중앙부 유리 난간을 표현했다. 5경간 교각 구성·차선 수·가로등 형태는 제작 가정이다.
- 육교는 계단 36단씩과 양쪽 진입부를 포함한다. 전체 길이는 진입부까지 약 52.4m다. 계단 포함 길이 49.6m는 진입부를 제외한 값이다.
- 보행판과 계단에 삼각형 충돌을 제공한다. 이동은 플레이어 컨트롤러의 계단 대응 설정에 따라 별도 조정할 수 있다.
- 징검다리에는 BankA/BankB, 선바위교에는 RoadA/RoadB, 육교에는 EntranceA/EntranceB 기준점이 있다.
- 원본 SCN은 로컬 좌표 에셋이다. `placements.json`을 통해 선바위교와 굴화리–다운동 징검다리를 울산 권역 지도에 배치한다. 범용 육교는 사용자 요청에 따라 보관만 한다.
- 징검다리는 선택한 지도 횡단 구간에 맞춰 진행 방향 길이를 약 172m로 조정한다. 선바위교에는 지형 관통 보정과 접속 램프를 적용한다. 원본 모델 치수와 월드 배치 치수를 구분하며 상세 내용은 `results/261004_PedestrianBridgePlacement.md`를 참고한다.
- 에셋 매니페스트의 로컬 AABB 및 고도 범위는 원본 기준이다. 월드 배치 위치와 적용 범위는 배치 카탈로그에서 관리한다.
- 범용 모델은 config/pedestrian_bridge_assets.json의 길이·폭·높이·분절 간격·계단 단수를 변경해 재생성한다. 기존 자산도 동일 설정으로 다시 생성된다.

## 실행 및 재생성
프로젝트 루트의 `previews/preview_pedestrian_bridges.bat`를 실행한다. 모델 선택은 상단 버튼 또는 1·2·3키를 사용한다. 드래그로 회전, 휠로 확대, Shift+드래그로 이동하고 Esc로 종료한다. 기존 맵 데이터를 읽지 않는다.

```powershell
& .venv_campus/Scripts/python.exe pipeline/processors/build_pedestrian_bridge_assets.py
```

생성 파이프라인은 임시 경량 Godot 프로젝트에서 에셋 생성·저장·재로드를 검증하고 개별 및 공용 매니페스트와 모듈 인덱스를 갱신한다. 미리보기 이미지는 실제 Godot 렌더이며 자동 재생성 대상에는 포함되지 않는다.

## 작은 교량 조명

약 120m 간격 및 양끝에 물리 반지름 0.1m의 작은 표시를 배치한다. 모델당 실제 광원은 1개, 에너지 0.2, 범위 4m, 50–100m 거리 소거로 제한한다. 원거리 확대와 그림자는 사용하지 않는다.

## 철로·교량 경량 표현

단색 재질과 성긴 반복 부재를 사용합니다. 접속점, 광원과 기존 충돌 형상은 보존합니다. 계단과 징검다리의 보행판도 보존합니다. 외부 텍스처는 사용하지 않으며 야간 표시의 내장 그라데이션은 8×8입니다.

- 품질 규약: `rail_bridge_low_poly_v1`
- 재생성: 프로젝트 루트에서 `.venv_campus/Scripts/python.exe pipeline/processors/rail_bridge_lowpoly/build.py`
- 생성은 독립 프리뷰 작업 공간에서만 수행합니다. 게임과 지도에 자동 적용하지 않습니다.
- 기존 PNG 프리뷰는 이전 표현일 수 있습니다. 현재 SCN을 독립 에셋 프리뷰에서 확인하세요.
