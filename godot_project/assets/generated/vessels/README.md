# 해상 선박 에셋
컨테이너선, 예인선, 보트, LPG선, 유조선, 어업용 소형선박의 경량 정적 3D 모델이다. 별도 외부 텍스처 없이 GLB 내부의 재질을 사용한다.

- Godot에서는 해당 선종의 `.tscn` 파일을 인스턴스화한다. 다른 3D 도구에서는 `.glb` 파일을 사용한다.
- 1 단위는 1 m이며 Y축이 위쪽, -Z축이 선수 방향이다.
- 루트 원점은 수면의 선체 중앙이다. `Waterline`, `Bow`, `Stern`은 향후 항로와 수면 연동용 기준점이다.
- 선체는 수면 아래 흘수 부분까지 포함한다. 배치 시 루트 Y값을 실제 수면 높이로 설정한다.
- `Visual`은 재질별로 병합한 정적 메시다. 운항, 부력, 충돌, 추진기 애니메이션은 별도로 연결해야 한다.
- 기존 월드와 로딩 설정에는 연결하지 않았다.
- 지리 좌표가 없는 모델이므로 매니페스트의 `bbox`와 `resolution`은 null이다. 로컬 경계는 `aabb_min_m`, `aabb_max_m`에 기록한다.
- 실제 선박 도면을 복제한 모델이 아닌, 종류를 구분할 수 있는 게임용 단순화 모델이다.

| 파일명 | 종류 | 길이 × 폭(m) | 삼각형 수 |
|---|---|---|---|
| container_ship | 컨테이너선 | 180 × 28 | 6,262 |
| tugboat | 예인선 | 30 × 10 | 1,478 |
| motor_boat | 보트 | 12 × 3.8 | 230 |
| lpg_carrier | LPG선 | 145 × 24 | 1,610 |
| oil_tanker | 유조선 | 210 × 34 | 2,242 |
| fishing_boat | 어업용 소형선박 | 18 × 5.4 | 1,106 |

## 재생성
프로젝트 루트에서 다음 명령으로 모델, 씬, 해시와 미리보기를 갱신한다. Pillow가 설치된 프로젝트 가상환경을 사용한다.

```powershell
& .venv_campus/Scripts/python.exe pipeline/processors/vessels/generate.py
```

`fleet_preview.png`는 생성된 메시를 직접 투영한 참고 이미지이며 Godot 렌더 결과는 아니다. 칸마다 독립 축척을 사용한다.
