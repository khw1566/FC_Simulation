# 공단 원경 에셋

28종에 각각 원경 LOD1·초원경 LOD2, 선택형 auto_lod 씬을 제공한다.

- GLB는 단일 표면·무광 단색, 외부 텍스처 없음.
- 개별 원경 씬에는 실제 광원·충돌·파티클 없음. 연결·배출구 마커는 보존.
- auto_lod는 근경 원본과 원경 2단계를 0.25초마다 선택한다. 5% 히스테리시스 사용.
- 기본 거리 350/1200/10000m 이상이며 모델 크기에 따라 확대. 카탈로그 참조.
- 대량 반복 배치는 GLB를 MultiMesh로 구성하는 것을 권장. 자동 씬은 개별 확인·소규모 사용용.
- 게임·공단 배치 데이터에는 자동 적용하지 않음. 전체 맵 성능 검증 없음.
