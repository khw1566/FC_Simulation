# 혼합 조립용 도로·보행로 에셋
도로와 보행로를 별도 모듈로 제작했다. 생성 에셋은 게임과 지도에 적용하지 않았다. 기존 도로 렌더러와 게임 씬은 수정하지 않는다.

## 구성

- 차도는 총 1~8차선이다. `lane_count`는 양방향 합계 또는 일방향 전체 차선 수다. 주행 방향을 자동으로 지정하지 않는다.
- 차도 유형은 도시 아스팔트, 지방도로, 고속도로, 공단 도로, 주거 공유도로, 비포장 차량도로, 콘크리트 차도다. 유형별 차선 범위는 `catalog.json`에 기록한다.
- 차도에는 직선, 45도 곡선, 90도 곡선이 있다. 도시 2·4차선에는 T자·십자 교차로가 있다.
- 보행로는 24개 표면 유형이다. 각 유형은 폭 1.5m·3m·4.5m 직선과 폭 3m의 90도 곡선을 제공한다.
- 콘크리트, 회색 블록, 줄눈 벽돌, 대형 석판, 횡방향 목재, 자갈 보행로에는 T자·십자 분기가 있다.
- 차도 차선 전환은 1↔2, 2↔4, 4↔6, 6↔8차선이다. 역방향 배치도 가능하다. 전환부에는 차선 표시를 자동으로 넣지 않았다.
- 보행로 폭 전환은 1.5↔3m와 3↔4.5m다. 낮은 접속면과 높은 보도면은 폭 3m 턱 낮춤 경사로로 연결한다.
- 경계석, 배수구, 난간, 방호울타리, 볼라드, 녹지 띠, 선형 배수 덮개, 점자블록, 계단을 별도 에셋으로 제공한다.
- 실선, 점선, 이중선, 횡단보도, 정지선, 화살표, 자전거 표시를 별도 에셋으로 제공한다.

## 보행로 표면

| 계열 | 제공 유형 |
|---|---|
| 일반 포장 | 콘크리트, 노후 콘크리트, 아스팔트, 탄성포장 |
| 블록·벽돌 | 회색 블록, 모래색 블록, 적갈색 블록, 줄눈 벽돌, 사선 벽돌, 투수블록 |
| 석재 | 대형 석판, 소형 석재, 불규칙 돌포장, 화강석, 수변 석판 |
| 목재 | 종방향 데크, 횡방향 데크, 해안 산책로 |
| 자연형 | 자갈, 모래, 다진 흙길, 숲속 오솔길 |
| 기능형 | 보행·자전거 공유길, 점자 유도블록 보도 |

## 좌표와 연결 규격

- 1단위는 1m다. Y축은 높이다. 직선 진행축은 Z축이며 길이는 12m다. 원점은 직선 구간 중심이다.
- 차도 표면은 Y=0m다. 차도 하부는 Y=-0.18m다. 일반 보행로 표면은 Y=0.15m다. 패턴과 점자 리브는 표면 위의 작은 돌출부다.
- 차선 폭은 3.25m다. 일반 갓길은 양쪽 0.5m다. 고속도로 갓길은 양쪽 1.25m다. 이 값은 범용 모델 규격이며 실제 도로 표준이나 측량값이 아니다.
- 곡선 중심선 반경은 `max(12, floor(width / 3.25) * 3.25 + 4)`m다. 차도와 해당 표시 모듈은 같은 반경을 사용한다.
- 각 씬의 `Start`, `End` 또는 방향별 `Marker3D`가 접속점이다. Marker3D의 -Z축은 에셋 바깥 방향이다.
- 두 접속점을 같은 위치에 맞추고, 두 바깥 방향을 서로 반대로 맞춘다. 접속 단면의 종류·폭·높이를 일치시킨다. 차도는 차선 수도 일치시킨다.
- 연결 에셋의 축척은 1로 유지한다. 비균일 축척은 차선 폭과 접속 규격을 바꾼다.
- 소재가 달라도 접속 폭과 표면 높이가 같으면 연결할 수 있다. 폭이 다르면 전환부를 사용한다. 높이가 다르면 경사로 또는 계단을 사용한다.
- T자 교차로의 세 방향은 -Z, +Z, +X다. 십자 교차로는 여기에 -X를 추가한다. 방향과 접속 위치는 카탈로그를 기준으로 한다.

## 혼합 조립

- `road_walk_mix_demo.tscn`은 차도, 블록·목재·석재 보도, 자갈·흙·숲길, 곡선, 분기, 폭 전환, 경계석, 녹지, 난간, 점자블록을 혼합한 독립 조립 예제다. 게임 실행 씬에는 연결하지 않았다.
- 차도와 보도를 나란히 놓을 때는 각 에셋의 실제 점유 폭을 더한다. 경계석과 배수로의 폭도 포함한다. 단순히 원점을 같은 위치에 놓으면 표면이 겹친다.
- 일반 차도 씬의 `RoadMarkings`는 독립 GLB 인스턴스다. 이 자식을 제거하거나 다른 표시 모듈로 교체할 수 있다. 차도 GLB 자체에는 표시를 넣지 않았다. 비포장 차도에는 기본 표시가 없다.
- 표시 모듈의 Y=0 기준을 대상 표면에 맞춘다. 표시 자체는 Y=0.004m 위에 있다. 보도에 놓는 표시와 점자 추가 모듈은 Y=0.15m 이동한다.
- 고속도로 표시의 가장자리 선은 차선 영역의 경계다. 갓길 전체 폭의 외곽선은 아니다.
- 경계석, 녹지, 난간은 보행 폭 안에 겹쳐 놓지 않는다. 부속물 카탈로그의 AABB로 점유 범위를 확인한다.
- 기존 산업 시설·역사·보행교·철도 에셋과 함께 사용할 수 있다. 각 계열의 `GroundOrigin`, 표면 높이, footprint를 확인하고 별도 위치를 지정한다. 다른 계열과 접속 단면을 자동으로 맞추지는 않는다.
- 외부 에셋을 새 도로 파일 안에 복사하지 않는다. 필요한 경우 별도 조립 씬에서 원본 씬을 인스턴스로 참조한다.

## 디자인 기준

- 기존 도로 셰이더의 어두운 회색 아스팔트 색을 기준으로 한다. 재질은 무광이며 외부 텍스처 없이 GLB 내부 재질을 사용한다.
- 소재별 색과 패턴은 구분한다. 연결 길이, 축척, 차선 폭, 접속 방향은 공통으로 유지한다.
- 반복 패턴은 폭 안에 배치한다. 연결부에 임의의 돌출 소품이나 무작위 단차를 넣지 않는다.
- UI와 프리뷰 배경은 흑백이다. 재질 구분 색과 백색·황색 표시 색은 에셋 표현에 사용한다.

## 범위와 확인

- 충돌체, 지형 밀착, 지도 배치, 차량 주행, 보행 경로 탐색, 교통 신호는 포함하지 않는다.
- 실제 위치·위경도 바운딩 박스는 없다. `bbox`는 null이다. 고도 범위는 로컬 모델 Y축 범위다.
- `preview_*.png`는 생성 메시의 경량 투영 이미지다. Godot의 조명·그림자 렌더 결과는 아니다. 프리뷰 카드마다 축척이 다르다.
- 기존 에셋 브라우저가 변경을 감지하여 목록에 추가할 수 있다. 프리뷰 실행파일은 재빌드하지 않는다.

## 재생성

```powershell
& .venv_campus/Scripts/python.exe pipeline/processors/road_assets/generate.py
& .venv_campus/Scripts/python.exe pipeline/indexer/build_asset_index.py
```

`profiles.py`는 규격과 유형을 정의한다. `mesh.py`는 도로 재질을 정의한다. `config/road_assets.json`은 그 규격의 기록이며 실행 중 설정이 아니다. 규격을 변경하면 코드와 기록을 함께 갱신한다. 생성기는 기존 기록과 불일치하면 중단한다.

## 혼합 교차로와 구조형 보행 데크 확장

중앙부·진입부·횡단 표시를 분리한 교차로와 하부 프레임이 있는 데크를 추가했다. 데크 난간·지지대는 독립 모듈이다. 기존 보행로와 같은 접속 단면을 사용한다. 상세 조립법은 [혼합 교차로·데크 지침](MIXED_JUNCTION_DECK_GUIDE.md)을 참조한다. `mixed_intersection_deck_demo.tscn`은 기존 에셋과 확장을 혼합한 독립 예제다.
