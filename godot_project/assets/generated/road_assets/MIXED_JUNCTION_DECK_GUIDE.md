# 혼합 교차로·보행 데크 조립 지침
기존 도로·보행로 에셋에 추가하는 독립 모듈이다. 게임과 지도에는 적용하지 않았다. 1단위는 1m이며 Y축은 높이다.

## 교차로 구성

- 중앙부 `mix_junction_*_core`는 교차하는 두 차도의 공통 영역만 포함한다. 중앙부 자체에는 진입부와 차선 표시가 없다.
- 중앙부의 `North`, `South`, `East`, `West`는 접속점이다. T자는 West 접속점이 없다.
- 차선 조합은 주도로·분기도로 기준 2·2, 4·2, 4·4, 6·2, 6·4, 8·4차선이다. 각 조합은 T자와 십자 중앙부를 제공한다.
- North·South는 주도로 차선 수를 사용한다. East·West는 분기도로 차선 수를 사용한다. 모든 접속면은 Y=0m다.
- 진입부 `mix_approach_*`는 길이 6m다. 아스팔트, 콘크리트, 회색 블록을 같은 규격으로 교체할 수 있다. 기존 일반 차도의 단면과 일치한다.
- 2·4·6·8차선 진입부를 제공한다. 고속도로의 넓은 갓길과는 직접 일치하지 않는다. 해당 단면은 일반 도로의 갓길 폭을 기준으로 한다.
- 진입부의 두 접속점 중 중앙부를 향하는 점을 선택한다. 중앙부 접속점과 위치를 맞추고 바깥 방향을 반대로 맞춘다.
- 진입부의 바깥 접속점은 같은 차선 수의 기존 차도와 연결한다. 다른 차선 수는 기존 차선 전환부를 사용한다.
- 진입부 씬의 `RoadMarkings`는 독립 GLB 인스턴스다. 표시를 제거하거나 교체할 수 있다. 진입부 GLB 자체에는 표시가 없다.
- 횡단보도 `mix_junction_*_crossings`는 별도 표시 에셋이다. 중앙부와 원점·회전을 맞춘다. 표시가 놓일 모든 진입부를 먼저 조립한다.
- 횡단 표시와 차선 표시는 도로 표면보다 조금 높다. 별도 표시를 중복 배치하면 표면이 겹칠 수 있다.

## 데크 구성

| 구분 | 제공 규격 |
|---|---|
| 표면 | 종방향 목재, 횡방향 목재, 풍화 목재, 석판 |
| 직선 | 길이 12m, 폭 1.5m·3m·4.5m |
| 곡선 | 폭 3m, 45도·90도 |
| 분기 | 폭 3m, T자·십자 |
| 광장 | 6m·12m 정사각형, 각 변 중앙에 폭 3m 접속부 |
| 경사로 | 길이 12m, 높이 차 1m, 폭 1.5m·3m·4.5m |
| 난간 | 목재·강철·케이블, 1.5m·3m·6m 직선, 폭 3m 곡선, 경사로용 |
| 지지대 | 폭 3m·4.5m, 높이 1.5m·3m·6m |

- 데크 표면과 기존 보행로는 `walk` 단면을 공유한다. 기본 접속 높이는 Y=0.15m다. 같은 폭이면 소재가 달라도 직접 연결할 수 있다.
- 표면 아래에는 강철 세로 보와 가로 보를 넣었다. 이 프레임은 표면 모델에 포함된다. 난간과 지지대는 포함하지 않았다.
- 폭 1.5m와 4.5m 보행로는 같은 폭의 직선 데크에 연결한다. 폭 3m의 분기·광장과 연결하려면 기존 폭 전환 모듈을 사용한다.
- 곡선의 접속 위치와 방향은 카탈로그와 Marker3D를 기준으로 한다. 곡선의 원점을 직선 구간 중심으로 추정하지 않는다.
- 광장의 각 접속점은 해당 변 중앙이다. 접속 폭은 광장 전체 폭이 아닌 3m다. 남는 가장자리에는 마감 난간을 놓는다.
- 경사로의 Start 표면 높이는 0.15m, End 표면 높이는 1.15m다. 상단에 기존 보행로를 연결할 때 보행로 원점을 Y=1m 올린다.
- 경사로는 게임용 외관 모듈이다. 접근성 기준이나 구조 설계 검증을 수행하지 않았다.

## 난간과 지지대 혼합

- 직선 난간의 바닥은 로컬 Y=0m다. 데크에 놓을 때 Y=0.15m 이동한다. 난간 높이는 1.1m다.
- 6m 난간 2개로 12m 직선 데크의 한쪽 가장자리를 구성한다. 난간 중심은 Z=-3m, +3m다. X 위치는 `side * (deck_width / 2 - 0.06)`m다.
- 광장용 1.5m·3m 난간은 남는 가장자리 길이에 맞춰 조합한다. 보행 접속부의 중앙 3m는 비워 둔다.
- 폭 3m 곡선 난간은 left·right 에셋을 제공한다. 표면과 같은 원점·Y축 회전을 사용하고, 난간 원점만 Y=0.15m 올린다.
- 경사 난간은 데크 경사와 같은 높이 차를 포함한다. 경사 데크와 같은 Z 위치와 회전을 사용한다. 양쪽 X 위치와 Y=0.15m를 적용한다.
- 지지대 상단은 로컬 Y=0m다. 일반 데크 프레임의 지지대 접속 높이는 -0.20m다. 데크 원점에 이 높이를 더해 지지대 상단을 배치한다.
- 지지대 기초는 상단 기준으로 아래에 있다. 실제 지형 높이와 수심을 확인하지 않았으므로 지형에 자동 배치하지 않는다.
- 난간이나 지지대 규격을 임의로 확대하여 맞추지 않는다. 표면 접속 규격은 축척 1을 기준으로 한다.
- 난간과 지지대는 다른 소재의 데크에도 조합할 수 있다. 위치, 길이, 폭, 경사 규격을 확인한다.

## 혼합 예제

`mixed_intersection_deck_demo.tscn`은 독립 조립 예제다. 실행 씬에 연결하지 않았다.

- 4차선 주도로와 2차선 콘크리트 분기도로를 별도 중앙부·진입부·횡단 표시로 조립했다.
- 기존 4차선 아스팔트와 2차선 콘크리트 차도를 진입부 바깥에 연결했다.
- 분기도로 끝에서 기존 턱 낮춤 경사로와 블록 보행로를 거쳐 광장으로 연결했다.
- 석판 광장에 기존 블록 보행로, 종방향 목재 데크, 풍화 목재 데크, 횡방향 목재 곡선 데크를 연결했다.
- 곡선 데크 끝에는 기존 콘크리트 보행로를 연결했다.
- 경사 데크 끝에는 높이를 맞춘 기존 석판 보행로를 연결했다.
- 직선·곡선·경사 난간을 각각 조립했다. 광장 모서리는 짧은 난간으로 닫았다. 지지대는 하부에 별도로 놓았다.

## 제작 범위

- 충돌체, 지형 밀착, 지도 배치, 신호등 동작, 차량 주행과 보행 경로 탐색은 포함하지 않는다.
- 로컬 AABB, 접속 위치·방향·폭·높이, 난간 부착 위치와 지지대 접속 높이를 카탈로그에 기록한다.
- 실제 위치의 위경도 bbox는 null이다. 고도 범위는 로컬 모델 Y 범위다.
- `preview_mixed_junctions.png`, `preview_decks.png`, `preview_junction_deck_mix.png`는 실제 생성 메시의 경량 투영 이미지다. Godot 조명 렌더는 아니다.

## 추가 모듈만 재생성

```powershell
& .venv_campus/Scripts/python.exe pipeline/processors/road_assets/extensions.py
& .venv_campus/Scripts/python.exe pipeline/indexer/build_asset_index.py
```

기존 `generate.py`를 실행하면 기본 에셋 생성 후 이 확장도 생성한다. 확장 생성기는 기존 기본 모델을 덮어쓰지 않는다. 기존 카탈로그와 매니페스트의 다른 항목을 보존한다.

## 단순화한 표현

- 표면은 단색과 큰 구획선으로 표현한다. 개별 블록, 촘촘한 목재 판재, 미세 색상 변화를 제거했다. 외부 텍스처는 사용하지 않는다.
- 곡선은 45도 3구간, 90도 5구간으로 줄였다. 접속점·방향·폭·높이는 유지한다.
- 난간은 적은 수의 기둥과 두 가로대로 표현한다. 케이블의 원통 메시와 촘촘한 세로 살은 제거했다.
- 하부 프레임의 가로 보를 줄이고 지지대의 기초·대각 보강을 제거했다. 지지대 상단 기준은 유지한다.
- 재질과 세분화 규약은 카탈로그의 `detail_profile=low_poly_flat_v1`로 기록한다.
