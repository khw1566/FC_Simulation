# 태화강 국가정원 시설물 에셋

정원에 배치하기 위한 범용 시설물 6종이다. 각 시설물은 `near` 근경 모델과 `far` 원경 모델을 별도 GLB 및 Godot 씬으로 제공한다. 실제 정원의 시설을 실측하여 복제한 모델은 아니다.

| 모델 | 근경 삼각형 | 원경 삼각형 | 용도 |
|---|---:|---:|---|
| korean_pavilion | 704 | 132 | 육각 목조 정자 |
| park_bench | 252 | 48 | 등받이 벤치 |
| backless_bench | 132 | 36 | 평벤치 |
| square_canopy | 232 | 104 | 3 × 3 m 소형 천막 |
| festival_marquee | 380 | 156 | 6 × 12 m 행사 천막 |
| picnic_table | 228 | 60 | 일체형 피크닉 테이블 |

- Godot에서 각 폴더의 `.tscn`을 인스턴스화한다. 다른 도구에서는 `.glb`를 사용한다.
- 1 단위는 1 m이며 Y축이 위쪽이다. 바닥 중심을 원점으로 삼아 두 모델의 배치 기준을 맞췄다.
- 외부 텍스처, 애니메이션, 런타임 스크립트, 물리 충돌체가 없는 정적 메시다.
- 재질별로 메시를 병합했다. 각 모델은 2~4개 재질을 사용한다.
- 원경에서는 판재 틈, 난간, 팔걸이, 받침판, 보강대, 창문 장식을 줄이고 주요 실루엣을 유지한다.
- 근경과 원경을 동시에 배치하지 않는다. 거리별 전환은 게임의 배치 관리자에서 연결해야 한다. 매니페스트의 권장 거리는 초기 조정값이며 자동 적용되지 않는다.
- 벤치 등 작은 원경 모델은 화면에서 수 픽셀 이하가 되면 렌더링을 생략하는 것이 적절하다.
- 반복 배치 시 같은 모델과 재질을 공유하고 필요하면 MultiMesh를 사용한다. 원경 그림자는 끄는 구성을 권장한다.
- `manifest.json`에 파일 해시, 삼각형 수, 로컬 경계, 재질 배치 수와 권장 전환 거리를 기록했다.
- `preview.png`는 생성 메시를 직접 투영한 비교 이미지다. 게임 씬과 지도 배치는 연결하지 않았다.

생성 소스는 `pipeline/processors/garden_furniture`에 별도로 보관한다.
