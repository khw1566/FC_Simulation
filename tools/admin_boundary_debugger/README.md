# 울산 광역 행정구역 디버거

울산 80km 맵의 실제 게임 월드 X/Z 좌표에서 행정경계를 그리고, 특정 위치의 포함 행정단위와 상위 경로를 확인합니다. 주소에 `?map=ulsan_metro_60km`를 붙이면 기존 60km 맵을 표시합니다.

## 실행

- `run_debugger.bat`을 실행합니다. 브라우저에서 디버거를 열고, 서버가 실행되는 동안 콘솔 창을 유지합니다.
- 프로젝트 루트에서 별도 정적 서버를 쓸 경우 `tools/admin_boundary_debugger/` 경로를 열면 게임 자산을 자동으로 불러옵니다.
- 파일로 직접 열었거나 자동 연결이 실패하면 `경계 파일 열기`를 눌러 `godot_project/assets/maps/ulsan_metro_60km/real_districts.json`을 선택합니다.

## 사용

- 행정 레벨 4/6/8/10을 각각 켜거나 끕니다. 표시는 바뀌지만 위치 판정에는 모든 레벨을 사용합니다.
- 지도를 클릭해 게임 위치를 검사하거나 X/Z 좌표를 직접 입력합니다. 판정 경로는 게임 서비스와 같이 가장 세부 경계를 표시합니다.
- 행정구역 이름이나 경계 코드를 검색해 폴리곤을 선택할 수 있습니다.
- `진단 저장`은 검사 위치, 포함된 행정경계, 행정경로를 JSON으로 저장합니다.

지도의 X/Z 값은 Godot 월드 미터 단위입니다. 중앙이 (0, 0), 북쪽은 Z 음수, 남쪽은 Z 양수입니다.
