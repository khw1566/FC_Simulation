# 저다각형 항구 모듈
범용 게임용 에셋입니다. 실제 항구 좌표나 수위를 지정하지 않으며 게임에 자동 적용하지 않습니다. GLB와 대응 씬은 하나의 모델입니다.

## 표현 기준
- 외부 텍스처 없음. 무광 단색 재질, 평면 법선, 중복 정점을 공유하는 GLB.
- 회전체는 6~8면. 곡선 방파제는 45도 3분할, 90도 6분할.
- 장식용 테트라포드는 기본 충돌 없음. 반복 배치 시 MultiMesh 권장.
- 등대의 색은 예술적 변형입니다. 실제 항로표지의 색과 운용 정보는 배치 단계에서 별도 지정합니다. 발광면은 단색이며 실제 광원 노드는 기본 꺼짐입니다.
- 컨테이너는 조립용 6m/12m 길이, 폭 2.4m, 높이 2.6m입니다. 실측 ISO 규격을 주장하지 않습니다.
- 첨부 사진은 어업용 크레인의 기둥·수평 지브·상부 지지 케이블·인양장치 외형 참고입니다.

## 접속과 혼합
- 1단위=1m, Y축 높이, 상판 완성면 Y=0. 시설의 GroundOrigin을 완성면 위에 놓습니다.
- Marker3D의 -Z가 바깥 방향입니다. 같은 profile·width의 접속점 위치를 일치시키고 바깥 방향을 반대로 맞춥니다.
- 기본 길이 12m, 좁은 부두 폭 6m, 넓은 부두 폭 12m, 방파제 폭 4m. 6m 격자를 사용하되 곡선과 폭 전환은 Marker 위치로 접속합니다.
- 방파제 곡선의 시작은 원점이며 직선의 원점은 중앙입니다. 원점 대신 Start/End를 정렬합니다.
- 방파제 4m→부두 6m, 부두 6m→12m, 부두 6m→기존 보행로 3m 어댑터를 사용합니다.
- 기존 보행로 접속은 표면 Y=0.15 기준입니다. quay_walk_adapter_3m의 끝이 해당 높이에 도달합니다. 도로·보행로 기존 생성기는 변경하지 않습니다.
- 해측 방향은 기본 로컬 +X입니다. 크레인의 작동 범위와 건물 footprint는 상판 폭과 별개이므로 배치 전 해측 여유 공간을 확인합니다.
- 크레인 레일 간격은 8m입니다. 레일 접속과 크레인의 RailStart/End를 사용합니다.
- 컨테이너 단품의 StackTop은 Y=2.6입니다. 적재 묶음은 독립 모델이며 단품을 필요한 수만큼 반복 배치할 수도 있습니다.
- 어항 조립 예제는 기존 어업용 선박 씬을 물선 기준으로 혼합합니다. 이미지 미리보기는 항구 기하만 표시하며 실제 선박은 조립 씬에 포함됩니다.

## 실제 지형 배치
- DEM 높이의 단위·수직 기준과 바다 수위의 기준을 먼저 통일합니다. 이 계열의 Y 값은 로컬 높이이며 실제 표고가 아닙니다.
- 항구의 완성 상판 높이 deck_world_y를 선택하고 상판·등대·크레인은 수평 또는 수직을 유지합니다. 지형 경사대로 전체 시설을 기울이거나 늘이지 않습니다.
- 육측 발자국의 모서리와 지지점에서 지표 높이를 표본합니다. 바다 쪽 지표 값이 무효이면 해당 지점의 해저 또는 별도 기초 깊이를 입력합니다. 바다 표면 값을 해저 값으로 사용하지 않습니다.
- foundation_top=-0.6, required_depth=deck_world_y-0.6-ground_y+0.25입니다. 상판·벽과 기초를 각각 배치하고 충분한 깊이의 매립 기초·호안·말뚝을 고릅니다.
- terrain_fit.support_plan(samples, deck_world_y)는 길이만 제안합니다. samples는 실제 DEM에서 얻은 (world_x,world_z,ground_y)입니다. 지형이 상판보다 높거나 준비된 깊이가 부족하면 준비 완료로 처리하지 않습니다. 무효 표본은 missing_terrain_sample로 남깁니다. family는 quay_foundation·pier_pile·seawall 중 선택하며 해당 계열에 실제 존재하는 깊이만 제안합니다.
- 단계별 상판 높이는 경사로로 연결합니다. 슬립웨이는 육측 Start와 바다측 End의 높이를 각각 확인합니다. 부두의 수평 구간을 지형에 따라 비틀지 않습니다.
- 테트라포드는 회전한 전체 정점의 최저 Y를 다시 계산하여 지표에 접촉시킵니다. 지형의 해측 가장자리에 개별 배치하며 묶음을 통째로 지형에 투영하지 않습니다.
- 실측 위치·항만 시설 배치·수위는 이 제작에 포함되지 않습니다. 세 조립 예제의 좌표와 수위는 연결 확인용 가정입니다.

## 생성과 확인
- 재생성: `.venv_campus/Scripts/python.exe pipeline/processors/harbor_assets/generate.py`
- 색인 갱신: `.venv_campus/Scripts/python.exe pipeline/indexer/build_asset_index.py`
- 카탈로그에 로컬 AABB·삼각형 수·포트 위치와 방향·간단한 충돌·기초 깊이·시설 작동 범위를 기록합니다.
- preview.png와 assembly_preview.png는 실제 생성 기하를 투영한 이미지이며 각 칸은 독립 축척입니다.
- 원본 게임·지도·임포터를 실행하지 않습니다. 에셋 프리뷰 실행파일을 재빌드하지 않습니다.
