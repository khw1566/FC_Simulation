# 프리뷰 실행파일
원하는 배치파일을 더블클릭하면 해당 독립 프리뷰를 실행한다. 실행파일은 프로젝트 루트를 자동으로 찾아 이동하므로 이 폴더 내부에서 실행할 수 있다.

- `preview_vessels.bat`: 선박 6종 선택, 회전, 확대 및 수면 표시 전환.
- `preview_pedestrian_bridges.bat`: 굴화리–다운동 징검다리, 선바위교, 범용 육교 선택 프리뷰.
- `preview_railway_bridges.bat`: 범용 철도 교량 5종 및 안양교–울산역 연결 세트 프리뷰.
- `preview_ulsan_airport.bat`: 울산 공항 프리뷰.
- `preview_ulsan_campus.bat`: 울산 캠퍼스 프리뷰.
- `preview_ulsan_heritage.bat`: 울산 문화유산 프리뷰.

선박 프리뷰는 별도의 월드 데이터 없이 선택한 모델만 읽는다. 마우스 왼쪽 드래그로 회전하고 휠로 확대한다. R키로 시점을 초기화하고 Esc키로 종료한다. 각 선박은 화면에 맞춘 독립 축척으로 표시되며 실제 길이와 폭은 화면 상단에 표시한다.

기존 프로젝트 루트의 프리뷰 배치파일 3개는 이 폴더로 이동했다. `run_game.bat`는 게임 실행용이므로 원래 위치에 유지한다.
