# 전체 에셋 프리뷰

`AssetPreview.exe`를 더블클릭하여 실행한다. `runtime`, `project`, `live_settings.json`을 같은 프리뷰 폴더에 보관한다. Godot나 Python을 별도로 설치하지 않아도 실행과 자동 최신화가 가능하다.

- 실행 중 원본 에셋의 추가·수정·삭제를 3초 간격으로 확인한다. 확인 간격에는 파일 복사와 임포트 소요 시간이 추가된다.
- 파일이 두 번 연속 안정된 상태임을 확인하고, 복사 전후 크기·수정 시각·내용 해시를 검증한 뒤 캐시에 반영한다.
- 변경된 GLB, 이미지와 씬 의존성은 프리뷰 전용 프로젝트에서 임포트한다. 진행 중에도 기존 프리뷰를 계속 사용할 수 있다.
- 반영이 완료되면 목록과 현재 선택한 에셋을 갱신한다. 현재 선택·검색 조건을 유지하고, 형상 경계가 같으면 카메라 구도도 유지한다.
- 원본 폴더가 없거나 파일이 잠겨 있으면 마지막 정상 복사본을 사용한다. 임포트 실패는 재시도하며 미완료 변경은 재실행 후에도 유지한다.
- 한 캐시에 하나의 실행기만 쓸 수 있다. 이미 실행 중인 프리뷰에 같은 실행파일을 다시 실행하면 중복 실행하지 않는다.
- 프로그램을 닫으면 감시를 종료하며, 해당 프리뷰가 시작한 임포터만 정리한다.

- 검색창에서 이름 또는 경로를 검색하고 유형 선택으로 3D, 생성 모델, 이미지, 데이터, 셰이더를 필터링한다.
- 목록은 400개씩 표시하며 이전/다음 버튼으로 이동한다.
- 3D는 드래그로 회전하고 휠로 확대한다. Shift+드래그로 이동하고 F 또는 전체 보기 버튼으로 구도를 복원한다.
- 부재 트리에서 노드를 클릭하면 해당 부재에 카메라를 맞춘다.
- 이미지는 이미지 +/- 버튼으로 확대하며 스크롤로 이동한다.
- JSON, GeoJSON, 문서, 셰이더는 128 KB 단위로 열람한다. 데이터 이전/다음 버튼으로 파일 전체를 볼 수 있다.
- 열차, 철도, 캠퍼스, 일반 건물은 게임에서 사용하는 원본 메시 생성기의 복사본을 호출한다. 일반 건물은 30개 샘플이며 캠퍼스와 건물은 평탄한 지표에서 확인한다.
- 간몬 수면은 게임 셰이더를 적용한 200 m 평면 샘플이다. 기타 셰이더는 소스를 열람한다.
- 저장된 3D 파일은 원본 씬의 스크립트와 물리 충돌을 비활성화하여 표시한다.
- 지도 전체 로딩과 게임의 자동 로딩 서비스는 실행하지 않는다.
- 기본 원본은 프로젝트의 `godot_project` 폴더다. 다른 경로로 옮기면 `live_settings.json`의 `source_project`를 수정한다. 상대 경로의 기준은 실행파일 폴더다.
- 원본 프로젝트 씬, 스크립트, 설정, 공유 매니페스트는 수정하지 않는다.
- `project`는 프리뷰 소스와 자동 갱신되는 복사본, `live/import_project`는 데이터 타일을 제외한 임포트 공간이다. 상태·로그·임포트 캐시는 프리뷰 전용 경로에만 쓴다.
- 실행기는 Windows .NET Framework를 사용하며, 저장소의 Godot 4.3을 `runtime/PreviewEngine.exe`로 복사해 재사용한다.
- 변경된 리소스의 의존성까지 다시 읽기 위해 [Godot ResourceLoader의 CACHE_MODE_IGNORE_DEEP](https://docs.godotengine.org/en/4.3/classes/class_resourceloader.html)을 사용한다.

실행기 기능을 변경했을 때 빌드 명령:

```powershell
& .venv_campus/Scripts/python.exe pipeline/processors/asset_browser/build_live.py
```

에셋 변경이나 프리뷰 UI의 `.gd` 수정은 재빌드 없이 다음 실행에 반영된다. 초기 캐시와 정적 보관용 패키지를 함께 다시 생성하는 명령:

```powershell
& .venv_campus/Scripts/python.exe pipeline/processors/asset_browser/build.py
```
